# Design: 陌生信号候选更新的同状态短期价值诊断

## Navigation

- [Research](../RESEARCH.md)
- [适应性总设计](ant-self-training-adaptation.md)

## Target Uncertainty

当前 45 参数方向修正的固定接受没有可靠收益。问题是候选更新是否至少在部分实际决策点改善后续局部反馈或搬运，而不是立刻新增更新网络。本诊断不训练接受决策，不检验从未接触复杂环境的泛化优势。

## Hypotheses and Discriminator

问题直接驱动。若接受一次候选的后续结果与跳过几乎处处相同，则当前候选对短时决策影响不足；若有正负两种结果，则存在需要判别的更新价值，但不能仅凭这点认定局部特征足以学习其价值。未来结果相同也可能来自时限或采样耦合，不能证明参数没有任何长期作用。

## Estimand / Target Contrast

在主轨迹禁止全部参数更新的条件下，同一存活个体接受一次当前候选与跳过候选，在后续最多 64 个物理步内的累计个体奖励、实际交付和死亡差。另记录整巢交付与伤害差，检查局部奖励和工作效果是否一致。它是模拟分支的局部干预效应，不是完整自学习策略长期效果。

## Population / Experimental System

沿用八只独立模型、共享信息素、512 步、探索与返巢双预算。基础检查点目录为 `logs/colony-reward/20260926T070617-2/` 的八份 `episode-0008-ant-*.npz`；冻结动作底座为 `logs/direction-motor/20260926T053106-2/seed-41/update-001200.npz`。执行记录保存全部输入哈希。

只用既有无害混合来源和持续静态伤害来源，不增加危险机制。两类局部响应相同，伤害后果不同。方向修正 45 参数，学习率 0.02、窗口 16、单次范数上限 0.05、总残差上限 1，均不调参。

## Sampling and Experimental Unit

种子固定为 9501、9502，各运行两种来源后果。每个世界最多 32 个决策点，总数不超过 128。每一时刻先完成全体行动、反馈和提案；只选择一个未终止且增量非零的候选，按窗口编号轮转优先个体，不能按未来收益选样。零增量和终止提案计数保留，不纳入存活个体分支。数量不足不追加种子补满。

独立单位仍是世界种子整巢轨迹。同一世界的候选彼此相关，两类条件也配对；只有两个独立世界种子，不提供泛化置信度或显著性主张。候选级标签仅用于机制诊断。

## Groups / Exposure / Intervention / Comparator

每点复制两个隔离世界、全体参数、局部记忆和个体随机流。接受分支仅焦点个体接受一次提案，跳过分支所有参数不变；之后两分支均不继续学习。其他个体虽参数相同，但行动随各自局部观察演化。两个分支都不能回写原主轨迹。个体死亡不在此刻重生，不生成下一代短期标签。

## Measurements and Timepoints

每分支最多 64 步，世界自然结束则提前停止，记录实际步数及终止。记录焦点奖励、交付、伤害、死亡与耗尽，以及整巢奖励、交付、死亡；接受权重、原候选、当前观察和末个隐藏状态分别保留。两个分支的结果字段绝不作为当前模型输入。

主轨迹动作逐步保存，参数每 64 步及结束时保存。本轮主轨迹始终跳过，参数快照应相同；它们不能伪装成训练进展。初始模型及实际动作可用于追溯主轨迹，但本轮不承诺任意中间点精确续训。

## Controls and Bias Protection

随机流从同一决策点复制，逐个体独立。使用相同未来随机流减小比较噪声，但单个随机延续仍不能证明稳定正收益。评价器已测试零增量恒等、非零接受只改变克隆、主轨迹不变和终止拒绝。工程冒烟使用独立种子 9599，只有两只、20 步和3步分支，不进入此次数据。

已知危险机制属于开发条件，即使此后用该数据训练，也只能作为已见机制的开发，不可再声称训练从未接触危险。固定配置不看结果后追加时限或样本，不挑选有利候选作为完整策略成绩。

## Primary Analysis Alignment

先检查配对完整性和主轨迹污染，再逐世界描述差值分布、正负和相同结果数量，同时列实际交付及死亡变化。保留所有候选。正负判定仅按数值容差 `1e-6` 区分奖励差，不是实际意义阈值。后续正式分析需在计算汇总前登记计划与数据身份，不把此采样设计当作完成分析。

来源规范沿用[总设计](ant-self-training-adaptation.md)于 2026-09-26 核验的 NeurIPS 报告要求；研究记录区分计划、实施、结果，未做外部预注册。

## Precision / Sample Size Rationale

128 是成本上限，不是功效计算。只有两个世界种子，没有足够精度检验模型优越性。候选全无行为差异时应先诊断反馈与短时评价，而不是扩大模型；若正负差并存，需要后续独立数据验证可预测性，不能立即称学习成功。

## Decision Boundary

最多一次完整采样；实现缺陷可修复并记录失败后重跑，结果不好不是重跑理由。结果相同、奖励与交付相反、两世界结论相反均如实保留。此后只考虑一个基于证据的接受决策训练方案，不能无限增加局部结构变体。本诊断不满足总目标的完成条件。

## Exploratory Analyses

按候选已知最小奖励、陌生响应、预算和携食状态查看差值分布可以作为探索。不能按未来筛选样本后再宣称输入特征有预测力；任何分类器应另固定训练与验证世界分区。

## Feasibility / Ethics / Access Constraints

计算模拟，无真实动物。代码、基础权重和运行权限已具备；无需新增下载、浏览器或服务。原 V2V 只读。预算最多 16384 分支世界步，最多 131072 个体行动；实际自然终止会减少计算。
