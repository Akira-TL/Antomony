# 行动学习与自训练的反馈来源

状态：2026-09-25 的有界文献与代码核对，供当前需求访谈使用。只有“已明确的需求”是用户决定；训练路线均是待讨论候选，未冻结研究设计，未训练或取得效果结果。既有研究草案、数据库和原 V2V 均未修改。

## 已明确的需求

- 神经组由每只蚂蚁自己的模型决定行进动作，普通规则组独立运行作对照。现有规则生成目标方向、神经网络预测动作后果的结构不符合这一目标。
- 不以预测下一步位移作为预训练目标；预训练须服务于实际的前进、转向和后续寻食搬运行为。
- 模型动作包含布尔的前进选择与 -1 到 1 的连续转向量。用户提出每刻最多转 10 度作为可调整的初始设想，尚未固定仿真时间间隔、符号方向、停止时能否原地转向和具体角度上限。
- 用户提出过记录训练权重、冻结变化小的模块，随后主动质疑其依据。该冻结方法没有被接受为设计。
- 每只蚂蚁的在线参数和学习状态保持独立。是否允许复制共同预训练初始权重仍未决定。

## 本轮回答的问题

在没有每一步正确转向标签的蚁群中，什么可观测反馈能训练行动策略，以及让模型学会控制自身更新？参数变化记录能否独立提供正确性信号？

### 行动需要任务目标，但不必有逐步标准答案

强化学习（Reinforcement Learning, RL）可以用执行后的奖励与累计回报训练行动选择，无须环境为每一步提供正确转角。策略梯度方法直接优化行动策略；近端策略优化（Proximal Policy Optimization, PPO）是可用于建立常规行动学习对照的候选算法，不是本轮已选定的实现。[Schulman 等，2017](https://arxiv.org/abs/1707.06347)

对本项目的推论：环境已经能观测食物拾取与实际交付，因而可以提供结果反馈；模型不需要提前知道远处食物坐标或正确路线。究竟把哪些结果当作收益，仍须由项目明确规定。没有任务目标、偏好、示范或其他评价约束，单凭模型内部参数不能推导出“朝食物前进更好”。

建议先讨论“固定仿真时长内实际交付的食物量”作为最终任务目标。首次有效拾取、时间消耗或接触代价是否用作辅助反馈，须再决定；它们不是论文直接给出的蚁群配方。

必须防止反馈鼓励错误行为：

- 不直接奖励局部信息素浓度；待在高浓度位置也可能得到高分。
- 不直接奖励累计移动距离；绕圈也能累加距离。
- 不直接惩罚所有转向；避障、回头和绕行需要转向。
- 停留与移动都要消耗仿真时间，不能仅靠“移动有代价、停留无代价”的设计诱导停住。代价尺度须避免使所有完成路径的收益都低于不行动。
- 若用到目标距离来辅助训练，必须区分合法可见目标与隐藏资源。欧氏距离也不能单独判定绕障是否正确。

奖励塑形（Reward Shaping）有保持最优策略的特定条件；势函数差分是一条经典方法。相关理论依赖其马尔可夫决策过程与边界条件，不能直接给局部可见、多蚂蚁共同改变信息素的系统作保证。本项目任何辅助反馈都需单独检查是否改变实际目标。[Ng、Harada 与 Russell，1999](https://ai.stanford.edu/~ang/papers/shaping-icml99.pdf)

### 学习控制本身可以由后续任务结果训练

最接近“网络学会何时改变自身”的参照是 Backpropamine。它在网络连接中保留可塑部分，由网络产生调制信号控制其变化；跨经历训练则优化任务表现。其迷宫实验只给局部墙体观测、前一步动作与奖励，隐藏奖励位置，网络仍可通过奖励学习行动和可塑性调节。该实验的迷宫布局固定，奖励位置每段经历改变；不能据此声称对任意新迷宫或本项目连续控制有效。[Miconi 等，ICLR 2019，方法第 3 节与实验第 4.2 节](https://arxiv.org/html/2002.10585)

另一条参照是元梯度（Meta-Gradient）方法：先用一段经历更新行动模型，再用后续经历的任务目标评价更新规则，沿更新过程调整控制学习的参数。原论文主要调整回报构造参数，不是本项目的模块冻结器。其“后续表现评价学习方式”的原则可供设计参考。[Xu、van Hasselt 与 Silver，2018，第 1 节](https://arxiv.org/html/1805.09801)

更广泛的研究也尝试跨环境学习整个强化学习更新规则，并以更新后模型的累计回报作为目标。它说明学习规则可以成为被学习的对象，但仍由外层任务目标和优化算法训练；不存在完全没有评价来源的自行判错。[Oh 等，2020，第 3 节](https://arxiv.org/html/2007.08794)

### 不宜从权重变化小直接推导冻结

以下为优化机制分析，不是实验结果：同一模块的变化小，可能来自任务已经学会、当前输入未激活该模块、梯度很弱、优化步长很小或参数化尺度不同。这些情形对“下一次是否应更新”的含义不同。网络模块也未必天然对应前进、转向、循迹等人类概念。

权重快照适合复现、审计和比较；若要学习更新控制，还必须关联当时可见输入、实际动作、实际参数修改及随后任务结果。单独的权重序列没有好坏标签。离线轨迹中若永远只有一种更新方式，也不能无条件识别其他更新选择会怎样。

## 候选的最小路线

以下是根据文献与当前需求提出的工程建议，不作为已批准实施计划。

1. 先建立独立模型直接输出前进与连续转向的行动学习对照。用相同局部观测接口，在短距离、容易获得任务反馈的环境学会完成任务，再增加路径弯曲、障碍、弱/强/过期信息素与拥堵。课程不向模型输入阶段名称或隐藏目标位置。布尔动作可以在训练时由可学习概率采样，执行时仍是布尔值；有界连续动作须使用相应的训练分布，不能把硬阈值当作普通可微函数。
2. 再让模型学习控制允许修改的行为参数。第一候选只设“本次跳过或执行有界更新”，便于判断学习时机是否真的有用。模块级选择在此成立后再讨论。候选参数变化可以来自任务反馈驱动的常规更新，也可以采用已训练的局部可塑性规则；两者是不同算法分支，不能含混合并。
3. 用多段变化经历训练控制学习的参数，优化更新后实际任务表现。可比较可微的调制强度与离散更新选择；精确为零的跳过不是普通 sigmoid 输出自动具备的性质。若使用离散选择，需要相应的策略梯度等估计方法；若阈值化连续输出，阈值必须披露，不能声称全由模型自行学得。
4. 在新环境检验已学更新方式。先固定控制学习的慢参数，让它根据当地经历改变每只蚂蚁自己的行为参数，就可以检验“预训练学会的自训练方法是否有效”。让控制学习的参数在现场继续改变，是额外一层能力，需单独决定与检验。

这条路线的因果顺序是：

```text
当前局部观察和个体历史
→ 模型输出前进与转向
→ 真实执行，记录局部事件和任务反馈
→ 用已经到达的经历形成候选参数修改
→ 模型决定跳过或执行修改
→ 下一次推理读取修改后的参数
→ 后续任务结果为此前的学习控制提供评价依据
```

立即反馈和延迟反馈可以并存。“后续拿到食物”不意味着最近一次更新必然正确，仍须通过跨经历的统计估计处理探索、运气和其他蚂蚁的影响。预训练期间若进行更新与冻结的配对分支比较，需复制完整世界、个体学习状态和随机数状态，各分支分别真实运行；不能用同一条更新后轨迹冒充冻结策略的行为结果。

第一轮对照至少考虑冻结、每次更新、固定更新规则、匹配更新次数的随机选择与学得的更新控制。行为改善也可能来自短期记忆或随机探索；要支持参数自适应的解释，应在保持感知、记忆与行动接口一致时干预参数更新。控制器恒开或恒关是否失败取决于环境是否真的同时包含“适应有益”和“修改无益”的可辨别经历，不能为展示而强行要求每种场景都切换。

## 与原 V2V 的关系

本轮只读核对：`docs/research/v2v-primitive-learning-signals-2026-08-31.md` 第 27 节，以及 `experiments/long_term_memory/run_predictor_learning_gate_credit_probe.py`。

可借鉴的边界是本轮先读旧参数形成输出，真实提交修改后再影响下轮；控制修改的路径接受后到反馈，避免由自己同轮产生的门值直接放大自身训练。

原预测门探针有明确的后续预测目标和构造情境。本项目行动学习的反馈拟来自任务回报，这不同于原 V2V 的局部预测纠正；必须明确它是本仓库的新候选，而不是原探针已经验证了蚁群学习。若用户要求连学习信号也严格沿用 V2V、排除任务奖励，就需要重新寻找与蚁群目标相连的可观察纠正来源，当前文献核对不能宣称这个缺口已解决。

## 尚待对齐

- 是否接受以实际搬运任务回报训练自主行动及学习控制；最终任务是总交付量、个体效率还是另有侧重？
- 局部反馈的可见范围：自身事件、同伴可见事件、蚁群总交付量分别可否参与训练？个体独立参数不自动回答奖励能否共享。
- 采用任务反馈驱动的常规候选更新，还是局部可塑性规则；控制学习的参数是否只在预训练阶段训练？
- 是否允许共同预训练起点、记忆形式、具体感知输入及参数修改范围。
- 停止时是否允许原地转向，转向上限对应的固定仿真时间间隔。

本轮未改变仿真与界面，未启动训练，未将论文方法或工程建议记为模型优势。
