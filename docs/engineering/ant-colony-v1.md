# 独立神经蚁群交互首版

## 当前授权与验收范围

用户接受：各个体独立预热（不是复制同一个权重模板）；局部数值传感；独立在线学习先行，回退后验。用户随后明确要求快速完成首版再完善。实现留在当前仓库，不修改 V2V，不携带旧预测器草案作为当前实验设计。

本版交付真实可运行演示，不宣称最优路径、深度强化学习已收敛、可塑性问题已解决或学习必然提高全群运输率。现场场景与人工干预是软件功能；学习收益是独立评价问题。

## 个体学习方法的决定

采用局部运动后果预测辅助的控制：每只个体拥有独立 NumPy 多层感知机（MLP），两个非线性隐藏层，预测候选动作的自身位移和接触。每只单独随机初始化，在单独生成的局部运动/接触练习上预热；运行中仅以该个体实际执行后收到的位移和碰撞反馈更新小型输出层。使用有限近期增量记录，但首版回退关闭，不生成虚假回退事件。

相比直接使用深度 Q 网络，局部下一步反馈无需等待稀疏搬运回报，也无需在当前比赛范围同时估计长期价值和训练目标网络。PyTorch 官方 DQN 示例展示了经验与目标网络等训练组成：https://docs.pytorch.org/tutorials/intermediate/reinforcement_q_learning.html 。此处是工程取舍，不是声称预测控制优于强化学习。

动作打分由预测位移向期望局部方向的投影、预测接触成本、惯性/探索项组成。神经输出参与候选动作排序；并非仅显示参数变化。期望方向由局部信息素、近距离且无遮挡的资源/巢穴观察、自身运动积分回巢和有持续性的随机探索组成。输入不包含隐藏资源坐标、全局导航图、最短路、人工干预类别或将来的反馈。规则的目标偏好、拾取/放下和信息素沉积明确属于手工先验，不声称自主产生这些行为。

运行期每只的参数、随机流、更新计数与最近经验独立。没有公共模型、梯度平均或经验广播。能够单独冻结一只或全群，检查一只的权重变化不污染其他个体。重复实现在数组层批处理不等同于共享，但首版以独立对象实现便于审计。

## 物理和信息素的决定

二维连续位置、圆形个体、轴对齐墙体，Three.js 只显示高度与灯光。移动按最大步长细分，每一步做墙体/边界投影与多体接触分离。接触处理计入单独指标，不能归功于神经避障。动态墙与当前个体或关键资源重叠时拒绝该操作并反馈原因，不偷偷传送个体。圆形、矩形与形状扫掠参考 Box2D 官方碰撞文档：https://box2d.org/documentation/md_collision.html 。首版不声称完整刚体动力学。

两类信息素：回巢轨迹与食物轨迹，离散二维网格，显式扩散与蒸发；只在两侧均可通行的相邻格子之间交换通量。墙体内值为零、边界不环绕。扩散系数与步长满足四邻域显式格式系数不超过1/4。移除墙不会凭空创建信息素。人工喷洒改变场，不向神经网络发正确方向或回退指令。

## 真实演示通路

观察 → 个体预测各候选动作 → 实际选择方向 → 体积碰撞与搬运 → 后到局部反馈 → 个体参数更新 → 后续新动作。每条学习误差是更新前预测与执行后反馈的差异。

主交互：暂停/继续、单步、倍速、重置种子、放墙/拆墙、添加资源、局部食物信息素、清空信息素、改变外部横向扰动、冻结全部/指定个体参数、选中个体观察。显示群体搬运、接触、神经更新计数、预测误差与独立参数变化。热力图来自真实场，不从轨迹装饰回写模拟。

Three.js 实例化绘制减少重复网格的提交成本，具体 API 参考 https://threejs.org/docs/#api/en/objects/InstancedMesh 。本地 FastAPI WebSocket 传递类型化快照，接口参考 https://fastapi.tiangolo.com/advanced/websockets/ 。选 TypeScript + Vite + Three.js 单页，不引入账户、云服务、数据库或全栈站点框架。服务只绑定127.0.0.1，使用项目脚本启停，不修改网络或既有代理。

## 验证计划（工程与探索性可行性，不是确认性研究）

先验证圆形/墙体不穿透、障碍拒绝、信息素不越墙、不环绕、独立参数和随机数隔离、冻结后不更新、神经输出真正参与动作选择、暂停单步和重置确定性。验证独立预热是否降低留出的局部运动预测误差；该检查不证明全群寻路效率。

开发配置与种子在首次跑成组评估前写入可重放脚本。成组比较同一外生种子、独立世界/信息素的冻结与在线条件，报告完整蚁群运输量、接触、更新前预测损失和耗时。完整世界是独立单位，不能将同场蚂蚁数当重复实验数。未测得收益就保留失败结果，不筛选成功种子，不用参数计数冒充效率提升。进一步的正式科研设计由 akira-research 接管。

首版完成指可启动、可交互、实际学习有执行和局部校验、无伪造效果。用户尚未实际观看，不提前声称用户体验验收通过。强学习收益与回退收益分别保持待验证。
