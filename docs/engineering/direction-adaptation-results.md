# 局部方向反馈与预训练更新器：开发诊断结果

日期：2026-09-26。执行源码提交 `419fd73`；运行前配置见[开发探针](direction-adaptation-probe.md)。本页记录固定开发配置的真实结果，不作为正式适应性优势结论。

## 执行与完整性

命令：`bash scripts/training/direction-adaptation.sh`。原始目录：`logs/direction-adaptation/20260926T055244-2/`。三份基础模型、五种扰动条件、三种更新方式，共 45 条轨迹、14,400 个体步。所有组起始偏移均为零；45 条轨迹中的 82 个基础动作参数均逐位不变。全部配置正常执行，没有筛除失败种子或参数发散条目。当前训练模块回归为 92 项通过。

每步保存修改前后的唯一方向偏移，原基础检查点保持独立；这些记录能重建实际发生的偏移与行为序列。没有为每步保存完整优化器状态，不声称可以从任意中间步继续原优化过程。

## 有符号差值

以下为第 96 步以后、包含换向瞬态的平均绝对方向误差差值，单位为度。差值为“更新组减禁止更新组”，负数表示方向误差较小。三个训练初始化等权平均；它们共享同一条方向指令序列，不当作广泛场景泛化证据。

| 条件 | 简单梯度更新 | 预训练 μLO 每步更新 |
| --- | ---: | ---: |
| 正常 | -0.1401 | +0.6418 |
| 持续正向偏转 | -1.5385 | -1.0657 |
| 持续负向偏转 | -1.4608 | -0.9936 |

| 周期变化 | -0.2517 | -0.5719 |

μLO 在所有轨迹每步都改动参数，均为 320 次，当前没有学习型跳过机制。相同配置下，持续偏转时简单梯度更新的方向误差更低；μLO 在周期条件下的方向误差更低，但正常与短暂条件下更高。保留这一混合结果，不把“外部模型已经预训练”当作它一定更好的理由。

有效前进量并不与方向误差完全同向：μLO 在正常和短暂条件中虽然方向误差增大，有效前进比例相对禁止更新仍分别增加约 0.00335 和 0.00562；持续负向偏转下则减少约 0.00208。不能用一个读数代替另一个，也不能事后只选择对某组有利的指标。

## 当前判断与下一步

本次证明外部更新器已能消费仅来自实际行动后果的局部梯度，修改前置方向参数而不改变冻结基础网络；未证明这是最佳梯度、未知信号已被理解、更新时机已经学会或运输效率提高。

下一步最有价值的是在独立开发条件上训练“修改或跳过”的判断，比较无修改、始终修改、简单规则判断和学习型判断，并保持同一个候选更新器与初始模型。训练标签可来自训练阶段同状态分支的后续差异，部署不能读取未来或真实干预类型。候选更新幅度、反馈近似误差与门控缺失目前都是竞争解释，不因正常条件劣化就认定原因只可能是缺少门控。

正式同规模多层感知机、无神经网络蚁群算法与自学习模型的复杂信号实验仍未完成。信息素识别、往返及未知来源组合仍是原目标中的必需阶段，不由当前方向探针替代。既有研究数据库与草案保持原状。
