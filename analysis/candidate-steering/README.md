# Analysis: 四步候选对实际动作分布的影响

- [研究首页](../../RESEARCH.md)

## Question / Target Contrast

在已发生四步窗口的同一局部观察上，实际写入前后，目标方向采样与冻结动作模型产生的前进、转向如何变化？特别检查受伤窗口是否出现目标方向更远离陌生来源、实际朝向却相反的情况。不是估计重新行动后的生存因果效应。

## Inputs and Data Freeze

已登记 `window-cadence` 数据，版本 `20260926T165559-3`。只分析四步配置下两个种子的固定接受及全部跳过组，四个世界全部活跃行动与全部实际写入，不按好坏挑选。原数据总计16世界；本次没有新采样或训练，原主要生存结果已知。

## Unit of Inference

两个世界种子；个体、生命、窗口和行动相关。以下计数仅描述既有写入，不作为独立样本推断普遍比例。

## Primary Analysis

从原始模型、个体种子、实际观察和逐条写入重建每一步方向采样，核对实际前进布尔值与转向量；每个已保存非零时点核对隐藏历史和随机状态。重建不通过则不解释效果。

对每次实际写入，在该窗口各行动前的固定观察上计算前后16方向概率，然后分别经过冻结动作模型。报告前进概率、平均转角、所选方向概率和总变差。不能用平均方向经过动作模型代替实际混合分布。

## Exploratory / Sensitivity Analyses

局部方向参照仅取第4至8接收器总响应的近处前后、左右差，逆向单位化。没有可用梯度时记缺失，不当作零变化。分别比较目标方向、一步标称朝向及标称位移沿该参照的投影。差值绝对值不超过1e-7不按方向改善或恶化计数。

按窗口实际新增伤害区分；某窗口只要有一次伤害即列入受伤窗口，投影变化仍是该窗口全部有梯度观察的平均，不声称每一次转向都造成了伤害。记录所有实际写入和无伤害窗口，避免只报告支持猜测的记录。

## Assumptions and Diagnostics

先核验完整输入清单、展开协议、源参数散列、原始反馈与窗口时序，再核验随机动作和周期快照。全部跳过必须无写入。近处响应梯度只表示本地信号差，不等于全局最安全方向；标称一步运动不包含碰撞、未来危险移动或后续循环轨迹。

## Outputs

待登记后执行。逐次修改记录保存在独立分析输出，规范汇总另存；不修改训练参数或原始轨迹。

## Reproduction

`scripts/analyses/candidate-steering.sh`，配置 `.research/analysis/candidate-steering/A001/config.json`。使用项目既有环境与锁文件，单线程确定性重建，最长300秒。

## Result Boundary

出现不利投影可以说明并非每次受伤后更新都朝该局部方向改善，不能单独解释完整世界死亡变化。即使全部投影改善，也不能据此证明避险成功。若存在目标与实际转向相反的写入，优先修正候选与动作对应问题；否则再定位短窗反馈归因，不扩大模型或窗口搜索。
