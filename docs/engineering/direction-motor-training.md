# 纯方向动作基础训练

## 边界

这是信号判断与自修改之前的可复用动作基础，不是自训练效果实验。网络采用现有 PyTorch，两个方向分量经 16 个双曲正切隐藏单元输出前进和转向，共 82 个参数。没有距离、目标坐标、上一奖励、到达标记或周期进度输入。旧 8771/8773 和旧检查点不修改。

允许复用前人模型，但复杂三维运动模型的现成权重不默认兼容本接口；学习型优化器的外部权重调查另见接入记录。这里保留低成本本地动作训练作为独立前置能力，不要求从零训练学习型优化器。

## 固定开发配置

- 单个体方向模仿，不做下一步位置预测；教师输出仅用于训练，不参与部署推理。
- 前进标签：朝向误差绝对值小于 60 度。转向标签：朝向误差除以每步 10 度并截断至 -1 到 1。这是明确的基础运动先验，不是未知环境学习结果。
- 批次 256，一半覆盖全圆，一半加密正负 20 度；避免仅学会转向饱和输出。
- AdamW 学习率 0.01、权重衰减 0.0001、梯度范数上限 1；转向输出用双曲正切限幅。没有把每个权重强行限制在 -1 到 1。
- 默认训练种子 41、42、43，每个 1200 次优化器更新；保存初始、每 100 次和最终权重。更新次数不是完整搬运回合数。
- 验收每个模型的 72 个固定初始方向和 8 条各含 8 次方向指令的序列，序列种子 8001。不用验收结果挑选训练中的最佳快照。
- 每个方向执行 48 步，前 32 步允许重定向，最后 16 步要求最大误差不超过 3 度、平均有效前进不少于理想步长的 95%。所有案例都通过才标记该基础模型通过；正负转向和背向失败均保留。

这些是运行前确定的工程门槛，不是经过统计功效分析的科研判据。存在难例失败时报告原始结果，不静默修改阈值或剔除种子。每步运动仅为平面转向和平移，没有障碍或信息素；通过不能推出已经学会归巢。

## 运行与产物

```bash
bash scripts/training/direction-motor.sh
```

脚本只启动短时离线训练，单线程 CPU，无浏览器或服务。每次创建独立 `logs/direction-motor/<时间与进程号>/`，重复目录被拒绝。控制台记录另在 `logs/direction-motor-<时间与进程号>.log`。

`config.json` 保存训练预算、软件版本和源提交；每个种子目录保存 `update-*.npz`、`training.jsonl` 和完整 `trajectories.json`；`results.jsonl` 保存有无通过及检查点 SHA-256。未通过返回非零退出状态，不删除结果。

检查点可由 `load_motor` 精确恢复为独立且冻结的模型，用于后续课程或轨迹检查。当前保存的是推理权重与训练步数，不包含 AdamW 状态，不能宣称可逐位继续原优化过程。尚未接入网页回放。
