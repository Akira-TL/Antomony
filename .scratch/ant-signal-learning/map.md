# 方向动作基础与信号判断、往返训练

## Destination

确定一份可以交给实现的训练方案：先重训只依赖方向信息的基础动作模型并验收冻结，再由信号层学习局部信号表示、方向层根据表示及记忆生成期望方向，完成单蚁探索、发现食物、归巢和再次搬运。明确输入接口、信号规则、课程顺序、验收条件，以及后续条件自修改的范围和进入条件。

终点是关键决定有依据且相互一致，不是本轮训练出模型或证明自训练有效。

- 本仓库 tracker 为本地 Markdown，规则见 `docs/agents/issue-tracker.md`。当前串行处理；状态文本不提供多 Agent 互斥。
- 已确认约束：原动作模型决定是否前进和转向量；信息素由代码固定释放；单蚁预训练；每只蚂蚁参数独立；归巢只读局部信号，不提供全局巢穴方位。

## Decisions so far

- [接收器直接区分信号类别，还是让模型从响应组合中辨别？](issues/02-receptor-information.md) — 用户选择混合感知，并将信号处理、方向判断与冻结行动分层。
- [如何完整保留第 2570 回合的动作能力与输入语义？](issues/01-frozen-interface.md) — 保存点包含实际参与动作的循环记忆；距离与低层反馈的兼容需要另作决定。
- [混合信号中的可辨别差异由什么承载？](issues/08-signal-features.md) — 基础成分允许明显的接收器选择性，复杂来源的组合意义通过学习获得。
- [没有可用信号时，持续随机探索方向由谁产生？](issues/03-exploration-ownership.md) — 方向层训练时采样方向，根据奖励学习探索。
- [离巢浓度扣费是训练奖励，还是环境中的实际能量消耗？](issues/09-exploration-cost.md) — 用户更新为低浓度探索、找到食物和携食返回三类正向得分。
- [哪些固定信号规则能让局部观察包含可学习的方向？](issues/04-observable-fields.md) — 完成现有接口核对与混合可辨别性分析；起始信号配置等待选择。
- [保留完整动作模型，还是只提取四连接动作部分？](issues/10-action-boundary.md) — 用户否定两个保留方案，要求方向输入的基础动作模型重训，验收后再冻结。
- [低浓度持续奖励如何避免停留和绕圈反复得分？](issues/11-exploration-credit.md) — 用户选择只按浓度计分，依赖自身释放，不增加位移或访问次数条件。
- [找到食物与返回的奖励按什么事件发放？](issues/12-task-credit.md) — 实际拾取、实际交付各奖励一次，不按闻到气味或驻留反复奖励。

## Not yet specified

信号表示与完整往返课程确定后，才具体化需要多长的记忆、如何处理多源交叉和暂时不可辨认的方向；不预设扩大参数规模能解决这些问题。

训练接口与可观测反馈确定后，才具体化条件自修改所需的参数分组、训练样本及延迟收益分配；不沿用已否定结构的写入头作为既定设计。

## Out of scope

- 本轮实现新模型、启动训练、重建前端或让用户试用未训练控制器。
- 将距离或目标接近反馈重新放入基础动作模型输入，或让新增信号层再次输出独立停走指令。
- 让模型学习信息素释放策略，或者用规则导航替代神经组的信号判断。
- 此时直接开展完整多蚁、规则组、多层感知机与自修改模型的正式对照。地图需留下该研究的进入条件，但不把比较结果当作本轮终点。
- 新增全局巢穴坐标、远距离食物方向或其他答案型行动输入。
