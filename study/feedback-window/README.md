## Source and Experimental Units

两个新整巢种子13101、13102，各重建16步与64步反馈组。每巢八个独立模型，种子为推断单位；同巢个体、时间点和两个窗口不是独立重复。

## Actual Groups / Exposure / Intervention

同向初始残差范数0.75，主轨迹全跳过，每64步选同一轮转位置，包含零候选。每种子每窗口7点，共28条候选记录，对应14个共同状态。各窗口的两个世界分别512步/9次交付、498步/16次交付，零死亡。

## Sample Collection and Processing

各点保留候选、跳过与已知恢复参照。没有补足上限或按收益挑点；非采样窗口照常完成候选及跳过，16步与64步的零候选总计数不要求相同。

## Assays and Measurements

后续延续统一最多64步。保存反馈、方向、候选、参照与288组定期模型及残差快照。当前尚未计算窗口收益差，逐状态匹配另由分析核验。

执行提交 `1d59700`；两份 `feedback-window-*.json` 与分组执行元数据固定参数和模型散列。项目锁定Python/PyTorch，单线程数值执行，源模型保持不变。
