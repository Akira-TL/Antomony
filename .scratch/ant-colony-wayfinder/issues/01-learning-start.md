# 开场从随机个体开始，还是展示独立预热后的继续学习？

## Question

选择哪种出生条件，既满足不共享模型，又符合两天开发和现场等待的要求？

A：每只随机初始化，现场从基本运动开始学习。B：每只独立初始化并独立预热基础能力，现场展示新环境中的继续学习。C：同一个已训练模板深拷贝给各个体，运行后独立学习。

助手建议 B；这是待用户选择，不是已接受的初始化方式。无论选哪种，运行时均不能共享权重、梯度或训练样本池；相同网络形状与相同环境规则不等于共享模型。

回答需明确预热是否允许、是否允许复制初始权重、哪些能力在开场前已有，以及现场必须重新学会什么。不得把预热形成的避障能力宣传成现场从零获得。

## Answer

用户本轮明确同意建议 B：每只个体独立随机初始化、独立生成预热经历、独立训练；不是复制共同初始权重。现场展示继续适应。
