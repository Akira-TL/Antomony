# 群体探索、搬运与预算返巢课程

## 本轮范围

用户明确同意多蚁共享信息素，并选择探索预算归零后仍有返巢体力。此前尚未执行的96回合单蚁方案撤销。采用 [群体与预算接口](colony-budget-interface.md) 的固定环境，先补充预算信号监督课程，再做一次8回合、每回合8只独立模型的短奖励试验。没有结果前不追加训练预算。

这仍是外部优化器执行的基础预训练，不是模型已学会控制自修改。采用带状态价值基线的演员-评论家方法，分类采样与策略/价值损失参考 [PyTorch官方示例](https://github.com/pytorch/examples/blob/main/reinforcement_learning/actor_critic.py)。本项目另用32步分段回报及价值自举，不声称复现示例基准。

## 起点与固定流程

起点为v3最后检查点 `logs/local-signal/20260926T064239-2/signal-001200.npz`，不选择中间最好轮次。动作底座仍为纯方向第41种子第1200步，82参数冻结。程序保存源提交、配置与两份源文件的SHA256。

1. 显式迁移至78维预算模型，新输入权重置零。预算监督课程1200次更新，批量256，学习率0.003，教师种子7201；每100次保存参数及优化器，保存第0步。预算耗尽时的梯度标签属于预训练先验，不能说成奖励驱动发现返航时机。
2. 将训练完的预算模型分别加载成8个独立模型，独立优化器、历史、教师采样器和动作采样器。共同初始化之后绝不广播参数或共享经历。训练环境种子11001至11008，每回合最多512个世界步。保持8只个体的各自参数跨回合延续，回合间重置局部记忆与世界。
3. 方向层输出对应16个等距方向，概率为 `0.8 * softmax(8 * 点积) + 0.2 / 16`。方向采样之后，冻结动作模型决定前进和转向；不由代码选择最低浓度或回巢方向。
4. 每个体32步或终止时分别更新。折扣0.995，非终止段使用下一状态价值自举，终止为零。演员项为负对数概率乘停止梯度的优势，评论家为平滑L1损失。附加64条预算信号样本的余弦方向损失，系数0.25；评论家系数0.5。AdamW学习率0.0003、权重衰减0.0001、梯度范数裁剪1。更新后断开历史计算图，保留实际16帧隐状态。
5. 第4至8接收器80个连接始终为零并冻结。信息素完全由代码固定释放；共享场每世界步只推进一次。探索、拾取、交付、实际预算返巢与耗尽奖励按接口文档执行，无距离进展奖励。

## 保存、验证与停止

群体第0、2、4、6、8回合分别保存全部8个模型及其优化器状态。全部训练和评估轨迹保存为压缩JSONL，包含局部观察、真实动作、隐藏值、位置、事件和个体更新次数。物理场未逐帧存储，但配置和动作轨迹支持重建；这不是完整中途断点恢复入口。

新开发场景9201至9204：预算训练前、预算监督后、群体奖励后，分别运行确定性输出与同规则采样，共24个群体世界；另对奖励后采样组遮蔽双信息素4个世界。配对相同环境和每蚁采样种子。每世界独立加载权重与环境。奖励训练期间训练发生器与评估分离。参数冻结、预留连接与动作底座校验失败即中止。

报告真实拾取/交付、预算耗尽返巢、空载预算返巢、体力耗尽数，不能用总奖励替代任务效果。比较监督后与奖励后的相同采样方式，防止把随机行动或监督先验当成奖励训练收益。本轮仅4个开发种子、一个训练运行，不是正式自修改效果研究；无论正负都保留，不外推MLP或规则组优劣。收益不明确时先诊断，不直接扩大网络、场景或训练量。

入口：`bash scripts/training/colony-reward.sh`；`--smoke`只验证两只个体、8步世界及保存链路，不能计入开发试跑结果。
