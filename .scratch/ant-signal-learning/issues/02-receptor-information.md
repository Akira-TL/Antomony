# 接收器直接区分信号类别，还是让模型从响应组合中辨别？

## Question

多个物理信号源与少量接收器如何连接？初版是否把归巢、食物轨迹、食物源气味和危险分别作为可区分输入，还是只给少量混合响应、让模型学习类别？明确两种方案给予模型的先验信息、仍需学习的内容，以及与后续未知环境适应目标的关系。

必须取得用户选择；不把“有四类信号源”自动解释成“四个自带类别标签的感知通道”。

## Answer

用户明确选择混合感知，由模型处理信号差异；结构细分为“信号源 → 信号层 → 方向层 → 行动层”。信号层学习表示，方向层生成期望方向，已有行动层保持冻结。

这不等于所有物理源必须产生完全相同的单标量，也没有确定响应维度或编码规则。可观察差异的具体载体另建决策条目，不把类别标签、源身份或目标答案偷偷送进网络。
