## Question / Target Contrast

固定196条训练、105条留出候选中，接受一次而非跳过的焦点实际交付和奖励有哪些正负零变化？任意二元接受器在这些固定独立配对上，最多能选出多少交付改善？不拟合、不扩样。

## Unit of Inference

8个训练与4个留出整巢种子；两个初始化条件、同巢个体和多次候选相关。逐候选数学枚举不是独立重复推断，不计算显著性。保留每种子、每初始化世界、每个体和世界内个体完整记录。

## Primary Analysis

从原始 `pairs.jsonl` 读取两分支的焦点交付计数及奖励；差值均为接受减跳过。交付正负零按整数精确比较，奖励正负零沿用旧课程1e-6数值容差。逐条保留两个原值与差值，分别汇总196条训练、105条留出，再按12种子、24世界、16个分区内个体和192个世界内个体报告；空组计数为0、均值为缺失，不补样。

对每一固定集合，交付改善的二元选择上界为 `sum(max(d_i,0))`，相应每候选均值除以集合大小，其中 `d_i` 为交付差。理由是每个选择贡献只能为0或该差值，逐项选较大者即达到上界。这个事后上界允许读取所有未来标签，不是可部署策略；独立分支不能相加解释为连续在线搬运量。每项均非正时，任何选择器的固定集合改善上界必为0，与网络大小无关。
