# 实时验收最小模型包

本目录只保存8775三组实时验收所需的25个模型文件，不包含完整训练日志、轨迹、科研数据库、原始样本或凭据。文件按原始NPZ字节复制，没有重训、改变参数或挑选新的终点。

## 文件与来源

| 目录 | 数量 | 每份参数数量 | 实际作用 |
| --- | ---: | ---: | --- |
| `motor/` | 1 | 82 | 纯方向输入的动作模型，运行中冻结 |
| `memory/` | 8 | 1429 | 14宽基础模型及64个零初始化记忆参数 |
| `mlp/` | 8 | 1650 | 17宽普通多层感知机对照，运行中冻结 |
| `gate/` | 8 | 141 | 旧接受模型，仅为当前加载与保存接口兼容保留 |

`manifest.json` 记录每个文件的相对路径、原本机来源、SHA-256、字节数、参数数量、完整数组结构及资格说明。来源路径仅用于溯源，不要求公开仓库同时包含这些原始日志目录。

同一种模型最多8份初始化，32只个体由它们分别独立复制，参数、记忆与随机流不共享；不能称为32份独立预训练。运行中的45个方向修正参数由执行器初始化，不是额外遗漏的检查点。规则组不加载本目录中的神经网络。

## 资格限制

- 这是工程验收所需的初始化模型，不是已证明优于普通模型的正式结论。
- 近期记忆使用前1、2、3、4步，稀疏记忆使用前4、8、12、16步；相应连接仍为零且冻结，不代表已经学会利用历史。
- 当前实时页使用固定接受的受限参数修正，每4次真实行动反馈处理更新窗口。基础信号模型与动作模型冻结。
- `gate/` 是旧目标下训练到200步的接受模型，未通过采用条件，也未按当前生存反馈训练。实时页不调用它决定接受或跳过更新。
- 两个神经组参数构成不同，不能仅依据表中的数量声称统计等效或研究比较充分。正式解释应使用项目已有研究设计及资格记录。
- 这些文件不包含运行中的环境、个体位置、更新窗口和完整随机状态，不是任意现场的断点续跑文件。

## 核验

在仓库根目录安装锁定依赖后，可核验文件散列、字段白名单、类型、维度及模型加载。不会启动服务或训练：

```bash
uv run --no-sync scripts/interactive/package-models.py
uv run --no-sync pytest -q tests/interactive/test_model_package.py
```

仅原始模型仍在本机时，增加 `--source-check` 可逐字节核对本包与原始来源。首次生成使用 `--build`，已有文件时拒绝覆盖；普通使用者无需重新打包。

安全核验禁止对象数组及未知归档成员；模型元数据只允许固定版本、训练阶段/步数、层宽、记忆步长以及动作模型种子和损失标量。所有数值参数必须为有限的32位浮点数组，并通过现有模型加载器核验。
