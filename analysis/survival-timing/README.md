## Question / Target Contrast

在已完成的生存反馈数据中，死亡前是否已经获得受伤反馈并实际修改参数？减少失败是否伴随更多巢边停留或更少移动？本分析描述实际时间顺序，不估计提前更新的反事实效果。

## Inputs and Data Freeze

版本 `20260926T161127-3` 的全部16世界，使用原始完整散列清单，不新增采样、训练或剔除。原始效果已可见，这是结果后提出的新探索性分析，不改原设计的采用判据。

## Unit of Inference

独立布局仍仅两个世界种子；个体生命、时间段及重复复活均相关，不把其数量当独立样本量。

## Primary Analysis

按真实复活划分同个体的连续生命。对受伤生命记录第一次受伤、之后第一次真实写入、死亡/耗尽终点及继承写入次数。死亡当步的写入不可能改变已执行的致死动作，单列为未在死亡前写入。观察期结束仍存活者保留未结束，不当作无写入失败。

每512步统计实际行动机会、前进请求、巢内半径0.65内停留、陌生响应非零、受伤、死亡、耗尽、交付和写入。位移总长排除复活瞬移；复活当步的真实位移也因缺乏具体出生槽位置而不计，另记漏计步数。不把前进请求等同于实际位移或探索质量。

## Exploratory / Sensitivity Analyses

分别展示两配置四组，不依据本结果选系数或重训。受伤到写入延迟是条件于已观察写入的分布，不能当所有生命的无偏反应时间估计。

## Assumptions and Diagnostics

输入完整散列核对；逐步写入增量须与提案记录一致，生命不能跨复活串接，非复活累计伤害不得倒退。分段死亡、耗尽、行动和写入与已核验汇总一致。确定性测试覆盖死亡同刻写入、此前写入、复活继承、瞬移排除与观察截止。

## Outputs

待正式执行，先登记本分析及代码。不会把时序相关自动解释为更新改善或恶化的因果效果。

## Reproduction

`scripts/analyses/survival-timing.sh`，配置 `.research/analysis/survival-timing/A001/config.json`，独立输出目录。

## Result Boundary

如果大量死亡发生在受伤后首次写入之前，支持检查响应延迟；如果多数死亡前已有写入，只能说明不能单用“从没更新”解释，还需检验更新方向和覆盖范围。即使长期减少活动，也不能仅靠本分析判断是否是合适的生存策略。任何新干预另冻结设计。
