## Question / Target Contrast

固定512步内，新17宽MLP、原14宽MLP和纯规则在食物与无食物世界的逐世界交付、预算返回、耗尽及探索半径，以及新MLP相对两参照的配对差。

## Inputs and Data Freeze

数据版本 `20260926T121232-2`，身份及完整253文件清单固定于 `8f32753`，104参数快照、96优化器状态、48完整轨迹。逐世界输出在采样时可见，本计划在首次汇总前登记，不声称盲法。预算、参数选择、阈值均在采样前固定。

## Unit of Inference

八个世界种子，任务及组别配对；同巢个体与时间步不是独立重复。只有一组八个独立初始化模型，不能把世界间变化当成训练初始化不确定性。

## Primary Analysis

先核对完整清单、实际协议、执行完成及非短流程、九份来源身份、参数分类、104快照及96优化器状态。检查初始参数可由种子重建、预留连接零、价值输出冻结、每份优化器六个参与训练参数的步数、形状、有限性与学习率。任何错误停止。

再核对48个唯一世界与零更新、连续时间步和个体数；从携食变化重建拾取/交付、从位置重算探索半径。按任务和组，八种子等权报告交付比例、无食物去重返回及耗尽比例、平均最大半径的均值与范围，保留全部世界记录。

完成步数只描述实际搬完的世界，并报告数量；新MLP减原MLP、减规则的配对时间差只用双方均完成的世界，其余仍保留交付差。负值保留，步数负差表示更快，不与负奖励差含义混淆。

按原设计的0.9交付、0.5返回、4.5探索半径筛查最低资格。三项均通过也不构成能力相当或统计等效，不做显著性或等效检验。

## Exploratory / Sensitivity Analyses

保留96条固定间隔方向训练诊断及所有参数，不以误差较低的中途点替代第2400轮。没有额外参数搜索或结果后子组分析。

## Assumptions and Diagnostics

当前环境无死亡丢食，携食真转假对应交付。返回与耗尽可同时发生；最大半径不是覆盖面积。范围只描述八世界，不当作置信区间。快照不是完整运行恢复点。
