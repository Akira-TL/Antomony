# 更新接受决策接口

## 当前状态

`src/mathhackson/training/foraging/update_decision.py` 提供可训练和可部署的决策模块，尚未用蚁群分支数据拟合。初始化输出0，严格正值才接受，初始行为为全部跳过。

输入140维：当前局部观察78、已有末个隐状态8、候选增量45、9项已见统计。统计为梯度范数、平均和最小已发生奖励、陌生响应、反馈步数、已见平均和最大相对熵、替代目标改善、回溯次数。逐项使用 `x / (1 + abs(x))` 固定压缩；没有从测试集拟合归一化系数。

输出是接受相对跳过的预测焦点奖励差。线性模型141参数，离线使用均方误差（Mean Squared Error, MSE）学习分支奖励差；优化器和训练预算由后续冻结研究配置确定。严格正值为接受条件，不在测试结果上调阈值。该线性起点可能表达能力不足，但不先扩大模型。

## 部署顺序

行动、取得实际反馈、形成候选、计算接受决策、接受或跳过、下一次行动。使用 `IndividualUpdateController.resolve(agent, observation)` 处理已经存在的候选。终止状态和零候选不能接受。异常预测保留待定提案并报错，不静默写入。

控制器复制传入决策模型，不共享参数或学习状态。接受只写当前个体45维在线残差，原循环方向模型和动作模型不变。部署不调用分支评价器、不推进额外随机数、不在线训练接受模型自身。

## 保存与边界

`UpdateDecision.save(path)` 独占创建版本化参数快照并记录训练步数；调用者应按固定轮次保存，与每只蚂蚁的基础和残差快照关联。`load` 校验版本、维度和有限值，不覆盖旧检查点。

现有58对含静态危险的诊断数据没有被用来训练本模块。下一基础课程计划在无危险、无减速、无周期变化的往返场景中加入初始在线参数扰动；未来分支只生成离线监督标签。此课程的可行性尚需实测，不能保证迁移到复杂环境。

工程验收7项，含合成正负收益学习、保存恢复、拒绝不写入、个体隔离、基础冻结、梯度隔离和真实世界中禁用未来分支的连续决策。这些不构成自训练改善或正式组间比较证据。
