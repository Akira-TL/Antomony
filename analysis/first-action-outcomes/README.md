## Question / Target Contrast

既有19701、19702首次受伤前各前四个不同个体状态中，16种首步方向后冻结推理32步的焦点失败、伤害、交付和实际生存反馈差异。

## Inputs and Data Freeze

原数据 `window-cadence`，版本20260926T165559-3；输入身份在配置固定。新分支生成前登记本分析，真实生成后追加新数据身份，不调整指标、取点或方向。

## Unit of Inference

整巢种子；同巢个体、时点、16分支相关，不将最多128分支作独立重复。

## Primary Analysis

按冻结设计，逐帧核对焦点失败、危险死亡、非危险耗尽、伤害、交付及生存反馈总和。失败以终止数计一次。对负失败数与实际反馈分别计算当前首步概率加权值、最大/最小值、20%均匀混合解析放宽上界。逐点完整报告，不用均值掩盖方向无差异或有害结果。

## Exploratory / Sensitivity Analyses

并列最好反馈方向与最少失败方向，不搜索目标系数，不进行旋转网格搜索，不扩样。

## Assumptions and Diagnostics

未来共同随机数固定，概率加权只积分首步，不是所有未来噪声的期望。解析上界取消旋转/参数约束，不等于该架构可实现最优；方向事后选择含未来信息，不能供训练。逐帧审计验证记录内部一致性，不是独立仿真实现。

## Outputs

已完成209文件、8点128分支及4096分支世界步逐帧审计。两个种子各四点，每点16方向的焦点结果均完全相同：失败1次、危险死亡1次、非危险耗尽0、伤害1.0399998426437378、交付0、实际生存反馈-2.039999842643738。主要结果范围与方向差均为0；不把128分支当128独立重复。

## Result Boundary

只对单次方向选择32步后果解释，不判断持续架构上界、可学习性、长期生存或模型优势。

本次8点的单次方向干预无判别力，按设计停止，不扩大时长、加点或训练。不能据此认定45参数无法表达避险、当前幅度足够、没有改善机会或自训练不可行。取点已接近伤害发生、干预只持续一步等均是与结果兼容的设计局限，但只是未验证解释。本次没有将未来分支结果用于模型参数或训练标签。
