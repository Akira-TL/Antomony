# 扩群与保留记忆的复活

## 已确认规则

新验收批次采用32只、4096步。危险死亡与返巢体力耗尽均结束本次生命，等待下一步巢内出现空位后复活。每只个体仍持有自己的参数、隐藏状态序列、随机流和写入次数，不新建模型、不转移其他个体的记忆。恢复探索预算及返巢体力，清除伤害、携食和接触状态。携带食物归还源库存，不计作交付，不奖励复活或补充体力。

32只使用原八份基础初始化，每份分别复制给四只；副本不共享参数存储、梯度或随机流。这是32个独立运行模型，不是32次独立预训练。初始最多八只在巢内，其余按编号等待空位后出发；复活进入同一等待队列，不凭空重叠。规则组保留自己的随机及规则状态，始终不创建神经网络。

## 死亡反馈与状态

死亡惩罚仍参与该个体刚发生窗口的候选更新。明确允许复活且仿真未结束时，学习接受、固定接受或全部跳过按各自原规则处理候选；不是死亡后强制修改。终止反馈处理完才允许复活，参数与已经分离计算图的历史保持原样。真正达到总时限或完成库存时仍不接受末端写入。

这一区别通过提案的 `continuing_after_death` 显式记录。旧批次缺省为假；不能把旧的“终止禁止更新”与新复活延续混为同一研究条件。保留隐藏状态不等于证明记忆已经学会有效利用；当前64个记忆连接仍为零且冻结。

## 计数与快照

逐步记录累计危险死亡、累计生命终止（包含耗尽及危险死亡）、复活、等待状态与实际源库存。复活只改变当前身体，累计代价保留；没有复活的旧记录沿用原累计到终止语义。

新批次每次参数快照同时保存隐藏状态和随机发生器状态到 `.memory.npz`。这些文件仍不包含完整世界、信息素或待计算梯度，不称无缝续跑检查点。

## 兼容边界

`ContinuousPlan.respawn` 缺省关闭。原冻结协议、来源模型、80世界分析及远距首轮20世界均保持原样。新批次只用于工程验收，后续科学比较需明确较长时限、更多个体、复活和库存的联合变化，不能把它归因于单一模型改进。

## 固定运行

```bash
env UV_CACHE_DIR=/tmp/mathhackson-uv-cache bash scripts/acceptance/prepare-reviving.sh
```

[配置](reviving-acceptance.json)保留远距19201布局与四种条件，五组共20世界。32只、4096步，库存384（每只12份），避免扩群后48份库存过早结束；每256步及终止保存参数和隐藏状态。预算、气味半径和强度、危险作用与学习参数不变。输出固定为 `logs/acceptance-revival/20260926-v1/`，已有目录拒绝覆盖。

最多八个独立进程执行不同世界，每进程一个PyTorch计算线程；个体和世界不跨进程共享模型、场或梯度。汇总顺序固定，不按完成速度挑选记录。进程数记入执行元数据，不属于模型输入。

## 实际验收

20世界已完整运行，执行来源 `2e7214d`。正常场景部分组完成384份库存后提前结束；移动危险各组保留到4096步。每个世界都保留负差值和重复死亡，没有把复活次数扣出死亡次数。

```bash
env UV_CACHE_DIR=/tmp/mathhackson-uv-cache bash scripts/acceptance/check-revival.sh
```

机械核对通过：71186帧、86887项提案、7776份记忆快照及97条源文件散列记录（含重复初始化路径）。核对范围包括每帧食物守恒、累计死亡/终止/复活递增、回巢后位置、实际写入链、参数快照对应、终止反馈语义与纯规则无参数文件；日志为 `logs/acceptance-revival/verification.log`。它不比较模型优劣，不替代正式研究分析。

全部316项训练测试、3项验收前端逻辑测试及前端构建通过。专用浏览器实际显示32个可选个体、4096步时间轴；播放由2243推进到2292步，随后暂停。第2486步两侧均显示32只存活，累计复活449/221、危险死亡446/215；交付差-16，未截断负值。截图 `logs/acceptance-revival-running.png` 已读取，食物、巢穴、群体及曲线没有相互遮挡。两个画布中心32×32区域均4096个非零分量、分别45/46种颜色。未进行手机尺寸检查。
