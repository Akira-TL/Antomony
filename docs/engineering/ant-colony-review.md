# 独立神经蚁群首版检查

本次采用当前会话内的非隔离双轴检查，不是独立 Agent 验收。基准为本轮开始时的 `039f43e`，检查对象为此后提交的独立模型、世界、服务、前端和测试；旧研究草案与数据库的前轮未提交修改不在本次范围。

## Standards

按项目 AGENTS 与首版契约检查。参数、随机数和训练经历按个体隔离；界面使用 TypeScript，通信使用 Pydantic 明确模型，服务仅绑定本机，启动/停止入口位于 scripts/colony，日志进入 logs。原 V2V 未修改。

本轮发现并修复了射线绘制使用了动作后朝向而非原观察朝向的问题，以及完整 pytest 入口无法导入既有 scripts 包的问题。分别由观察姿态字段与项目测试路径配置解决。33项 Python 测试及前端类型检查通过；运行构建成功。

剩余工程限制：多体拥堵采用迭代接触分离而非通用刚体求解器；Three.js 构建包大于默认500kB警告阈值，当前本地加载不依赖远端资源。两者不是已经通过所有极端性能条件的声明。

## Spec

已有：32个独立初始化与独立预热的模型、局部数值观察、神经输出参与候选方向选择、在线输出层更新、圆形接触、墙界信息素、真实搬运、人工编辑与冻结控制、浏览器可视化。七项真实服务操作验收通过。

需要保留的一个效果验证缺口：完整的“在线学习提高运输效率”尚未建立。固定配置的3组开发试跑中，在线条件在实际轨迹上的预测误差和接触率均较低，但总搬运块数23比23，不能宣称运输量提升。自动回退与真实像素输入已按用户选择排除在首版验收之外，而不是隐藏未实现功能。

用户本人尚未完成视觉与交互反馈，因此相关 Wayfinder 条目保持开放；当前可交付的是有真实模型与操作的可试用首版，不是全部研究问题已解决。

## 结论

标准轴：两项发现已修复，无新发现的启动阻断；规格轴：核心操作已实现，一项学习效果主张仍缺充分支持。进一步打磨应以实际试用和独立世界对照为依据。
