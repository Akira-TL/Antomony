## Question / Target Contrast

两个新世界种子、32只及最多4096步的移动危险条件中，取消空载返巢奖励相对保留2分的逐世界交付、危险死亡、体力耗尽和空载返巢次数差。

## Inputs and Data Freeze

输入身份 `return-reward-ablation`，批次 `20260926T142153-2`，两个完整配置各10世界。原始目录在 `logs/return-reward-ablation/`，已于采样结束后用完整散列清单冻结。当前分析尚未执行；不使用工程种子19201或旧近距对照结果计算本次差异。

## Unit of Inference

整巢世界种子，只有两个独立布局和同一个八模型初始化库；五组、奖励配置、个体和时间窗相关。每种更新方式分别配对，不合并个体制造样本量。

## Primary Analysis

先核对两配置仅改变空载返巢奖励及来源参数相同。完整文件散列、复活及死亡累计、食物守恒、提案至参数写入、快照链条由机械检查验证。再从真实事件重建奖励账、交付、死亡、耗尽与空载返巢，核对世界汇总。

差值统一为取消奖励减保留奖励；交付正值较好，死亡负值较好。报告所有种子差值和两种子等权平均，不比较不同定义的总奖励。全部跳过、冻结MLP及规则的全部观察、动作、身体、库存和事件须逐帧一致，允许奖励及更新提案诊断值不同。学习接受与固定接受分别按设计的两种子联合条件判断是否值得进一步验证，不将平均值掩盖的负种子排除。

## Exploratory / Sensitivity Analyses

逐个体按真实提案边界重建奖励窗口，统计含空载返巢事件的窗口、其中出现陌生接收器响应的窗口、非零提案及实际写入。不同配置各自描述，不把这些窗口视为独立样本。

## Assumptions and Diagnostics

两种配置运行之间不修改模型、仿真、参数来源和预定随机种子；执行器记录实际提交及模型散列。首个行为差异按完整帧的观察、动作、身体和事件确定，忽略奖励和写入计数。缺失或重复世界、无更新对照不一致、异常奖励账均使分析失败，不自动修剪。原始汇总随运行可见，不称盲法；正式结果生成在分析登记之后。

## Outputs

尚未生成。计划保存 `summary.json`，含逐世界指标、配对差、首个行为分歧、奖励窗口统计及预定判定。另保存两个批次的机械核对日志。

## Reproduction

入口 `bash scripts/analyses/return-reward-ablation.sh`，修正后的配置 `.research/analysis/return-reward-ablation/A002/config.json`。结果写入独立输出目录；已有结果时拒绝覆盖。测试使用确定预期值及真实短规则轨迹，不依赖本次效应方向。

## Result Boundary

当前没有结果。两个新种子只支持本次奖励修改的开发判断，不证明一般自训练优势、接受时机学习有效或完整循环记忆能力。去除空载返巢奖励不是自动修复，也不意味着撤销低能量回巢行为需求。
