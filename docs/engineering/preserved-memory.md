# 保留基础功能的循环记忆

## 目的与边界

无线索探索补课未通过采用条件，结果见[补课分析](../../analysis/exploration-course/README.md)。此次不继续调整旧课程，而是复制已训练多层感知机（MLP）的全部基础参数，加入零初始化记忆连接，先保证初始行为不变。

这是一项工程兼容性检查，不是记忆效益或自主学习效果实验。不替换旧训练服务默认模型，不覆盖旧检查点，不沿用失败的接受模型声称更新有效。

## 结构

输入仍为局部接收器和自身状态，不加入目标距离、隐藏食物坐标或全局巢穴方向。前馈网络的预处理及计算顺序不变，在第二个隐藏层的双曲正切激活之前加入记忆贡献。

- 近期位置为前1、2、3、4步，稀疏位置为前4、8、12、16步，两条第4步路径各有独立参数。
- 每个位置具有8个逐维连接，共64个新增参数，不跨维全连接。
- 每个连接经双曲正切函数后参与加权，8个位置之和除以平方根8，隐藏状态再经双曲正切函数；这不等于保证所有循环动力学稳定。
- 连接全零时，任意正常有限历史不改变前馈输出。连接启用后，隐藏状态会依赖指定历史，历史不是只记录不用。
- 基础网络深复制并冻结；记忆训练阶段只开放这64个参数。每蚁权重、记忆与随机流独立。

MLP有1365个参数，加82个冻结动作参数合计1447；新记忆模型为1429加82，共1511。将来若再接45个方向修正及141个接受决策参数，总量为1697，比原MLP多约17.3%，尚不能称为严格参数匹配。

保存格式为 `local-mlp-memory-v1`，记录两组时间位置及全部参数；加载拒绝不兼容版本、错误维度及非有限参数。旧MLP加载器不把新模型默默当成旧模型。

## 下一边界

零连接只是保持初始功能，不代表学会使用记忆。来源模型仅经过信号方向训练，价值输出没有经过奖励校准；不能把它作为可靠的回报估计继续盲目训练记忆或接受决策。下一阶段应先明确自主更新使用的实际反馈及价值估计训练方式，再固定有限预算实验。现有方向修正和接受模块还未接入此新模型，完整复杂环境对照仍未完成。
