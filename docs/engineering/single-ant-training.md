# 单蚁训练器的工程契约

这是交互开发训练器，不是正式效果实验，也不是原论文复现。原双场景、规则组与 V2V 均不参与训练。每个训练会话只有一只蚂蚁和一份独立模型。

## 运行

安装依赖 `uv sync`，构建 `npm --prefix web run build`，通过 `bash scripts/training/start.sh` 启动。默认地址 `http://localhost:8766/training.html`；占用时使用 `PORT=8767 bash scripts/training/start.sh`，不停止其他端口服务。停止时向 `scripts/training/stop.sh` 传入相同端口。定向检查入口为 `bash scripts/training/check.sh`。服务启动后训练默认暂停。

若 Agent 执行环境会回收后台子进程，用 `bash scripts/training/start.sh --managed` 交给用户级 systemd 临时托管。托管只启动本项目的 `serve.sh`，不安装永久服务，不调整网络配置；停止仍使用同一个 `stop.sh`。

## 任务与评价

- 新会话默认使用随机食物课程：每回合在蚂蚁周围 2.5 至 6.5 单位的范围内重新生成一处可见食物，方位覆盖前、后、左、右。直行和左右 60 度课程保留为单项练习。
- 模型输入相对目标方向的余弦与正弦、距离、上次动作、上次奖励、碰撞、进展、回合进度和常数。预留的两类信息素各三个采样值在当前基础课程中均为零，尚未训练信息素循迹。
- 模型直接输出是否前进、连续转向。每个仿真步是 0.1 秒，前进时位移 0.18；转向输出经过双曲正切限制在 -1 至 1，默认乘以 10 度。没有规则方向器、轨迹预测损失或隐藏食物位置。
- 每步奖励为 `2 × 到可见食物距离的减少量 + 0.5 × 相对食物方向误差的减少量 / π - 0.01 - 0.1 × 碰撞 + 2 × 触达`。方向误差在执行转向和位移前后测量，误差变大时该项为负；它只提供训练反馈，不替模型选择动作。距离小于 0.4 判定触达，每回合最多 96 步。

## 模型与三阶段

模型是 39 × 16 的可自修改权重矩阵，共 624 个参数。前两行产生动作，第三行决定是否写入，其余行产生读取位置、写入位置和写入幅度。内部写入使用两个位置读取值之差的外积；写入对象包括产生写入控制的参数自身。数学写入操作、任务评价、数值范围固定。

1. 基础动作预训练：只训练四个行动连接：前进输出读取食物方向余弦、食物距离和常数，转向输出只读取食物方向正弦。其余行动连接从零初始化并在本阶段冻结；禁止自写入，其他 37 行也冻结。模型矩阵仍是 39 × 16，阶段切换后整组基础动作锁定，避免后续写入破坏已学会的转向。
2. 自修改预训练：进入后锁定两行动输出行，外部训练和内部写入均不可再改动基础动作。此前回放显示开放转向偏置会造成触达率骤降。旧矩阵写入器目前只可修改非动作行，因此本阶段暂不构成有效的行动自适应；后续实验将以独立、受限的行动参数接入写入通路。进入前仍用当前模型在 12 个固定食物方位做只读、确定性的基础动作检查：目标左右两侧各六个方位，分别至少触达五处才允许切换。
3. 自主运行：停止外部梯度训练，只保留模型决定的内部写入；不等于已经获得有效的自训练能力。

外部训练采用回合回报的策略梯度（REINFORCE），折扣 0.97、学习率 0.05、梯度范数上限 1、动作熵系数 0.003。前进与写入判断在预训练阶段按伯努利分布采样，转向按标准差 0.35 的正态分布采样后做双曲正切变换；自主阶段使用确定性判断与均值。写入判断只分配下一步开始的回报。回报基线仅来自已完成回合。

转向输出在双曲正切变换前乘以 3，使每步最大角度不变时模型仍能使用足够大的左、右转角。基础动作预训练还用可见食物的相对方向正弦提供转向辅助损失，目标原始输出为 `4/3 × sin(相对方向)`，权重为 8。该损失只在基础训练时参与外部更新；运行时没有按食物方位替模型指定转向。

本原型跨步对内部写入求导，在每个回合边界截断计算图。外部更新施加在回合结束的实际权重上，保留之前内部写入，不重置到初始矩阵。这是受自指权重矩阵启发的工程变体，不将它标为严格复现：见 [ICML 2022 原论文](https://proceedings.mlr.press/v162/irie22b.html)。

## 冻结与记录

- 冻结同时阻断外部更新和内部写入；全冻结时仍可行动，但全部参数逐位保持不变。
- 切换阶段、课程、冻结或角度上限会暂停并记录当前片段，不对这个中断片段执行外部更新，然后重置环境。模型参数保持。
- `logs/training/<会话标识>/episode-*.npz` 保存每回合开始、外部更新前、结束权重，以及逐步权重、观察、动作、奖励、写入判断和冻结掩码；同名 JSON 保存阶段、课程、结束原因和计数。
- 界面中的参数值、初始值、最近内部改变量、最近外部改变量均来自实际模型；不使用示意参数。记录不写入研究数据库。
- `/api/training/trace?row=…&column=…` 提供最近最多 256 条真实逐步权重快照，区分跳过、自写入和回合末外部更新。右侧曲线显示所选参数的实际变化；暂停时曲线停止，基础阶段逐步平直、回合末才可能改变。轨迹为易失的当前会话窗口，长期完整记录仍以逐回合压缩文件为准。
- 独立页面的 `.network` 显示全部矩阵；点击单元、使用方向键或指定行列可定位任一参数。可训练状态按单元呈现，基础阶段未启用的行动连接和冻结行均使用灰色、斜线及文字标识，不只依赖颜色。
- 页面刷新保留服务端会话；重置回合保留参数。重启训练服务创建新模型，会话日志仍保留。当前下载是参数审计记录，不是可恢复随机数与优化进度的完整检查点。

## 证据边界

工程验收只检查真实计算、动作因果顺序、冻结不变量、状态隔离和可操作界面。参数发生变化、训练损失下降或某次到达目标都不能证明学会有效自修改。之后须固定训练与测试任务划分，比较外部更新停止后的冻结模型、始终更新与模型控制更新，并计入更新成本、多个随机种子和失败结果，才能讨论效率优势。
