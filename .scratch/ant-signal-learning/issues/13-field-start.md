# 第一阶段采用怎样的混合感知与固定信号规则？

## Question

依据[信号场调查](../../../docs/engineering/mixed-signal-field-options.md)，基础信号使用选择性接收器、复杂来源产生组合响应后，如何固定成分清单、采样位置和信息素释放规则？用户举例的三个基础接收器尚不等于已经删去两类轨迹与食物源气味中的任何一种物理来源。

需明确首版危险场是否只留感知接口或同时进入课程，以及未知环境首先改变源的组合、强度和动态还是响应特征本身。固定可逆混合保留分通道方案的信息量，不可将其当作通用未知类别识别已经得到验证。

当前优先澄清：用户选择只按当前离巢浓度给探索奖励，依赖自身释放升高浓度。是否在空载探索期间按仿真时间持续释放，即使原地转向或停留也释放？原来的定距沉积候选不能默认实现这一目的。建议先连续释放并明确释放、扩散蒸发、奖励采样的顺序；浓度奖励范围与路径梯度由后续课程统一校准。此建议尚未获用户确认。
