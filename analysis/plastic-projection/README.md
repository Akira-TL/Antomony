## Question / Target Contrast

只改变方向读出归一化方式、固定参数数量和预算，候选能否比旧模式提高合成方向收益并形成有用的接受与跳过？同架构、同初始化训练后是否比训练前改善？这是前一失败可见后的探索性选路，不冒充既有预测。

## Unit of Inference

## Primary Analysis

正式奖励为所选单位方向与当帧隐藏目标方向的点积，不扣外层优化使用的写入成本。分别计算第5至96帧和第73至96帧的每回合平均奖励，在初始化、条件、生成种子、回合编号上配对，先求回合差，再对64回合等权平均。两关联条件的联合差按条件等权平均，不跨初始化平均掩盖失败。

保留每架构、每初始化、每评价时点内学得接受减全部跳过、全部接受和等次数随机接受的差；另计算候选训练后减旧模式训练后的学得接受，以及候选训练后减同初始化候选训练前的学得接受。每种模式与时点的四组原始回合记录保留，不把训练前参照称为普通MLP。

候选的两个初始化必须分别同时满足全部要求：

1. 训练后持续关联相对全部跳过的两个窗口差均至少0.03；原方向参照的两个差均至少-0.02；两关联条件等权的第5至96帧奖励相对全部接受和等次数随机接受均至少0.005；两关联条件合并的接受和跳过各至少10%，并有真实非零写入。
2. 候选训练后相对旧模式训练后的学得接受，在持续关联两个窗口均至少改善0.03，原方向参照两个窗口均不低于-0.02。
3. 候选训练后相对同架构、同初始化训练前的学得接受，在持续关联两个窗口均至少改善0.03，原方向参照两个窗口均不低于-0.02。

任一初始化失败即停止该配置，不延长、不换种子、不降低门槛、不挑中间保存点。只有方向改善而没有选择性更新，仍不通过迁移资格。

## Assumptions and Diagnostics

完整核验两架构的全部文件、保存点、两个评价时点及四组配对。两架构初始参数必须逐值相同；关闭写入组的行动跨架构和训练前后逐值相同，其隐藏状态允许不同。核验保留接收器4至8为零、实际奖励与方向一致、四帧接受边界、跳过不改在线连接、单次写入上限0.25、累计上限2、等次数日程逐回合计数、摘要与原始记录一致。

每模式保存0/25/50/75/100/125/150结构参数；每25轮训练轨迹标明其使用的前一版本。训练前评价位于独立`untrained/`目录，结构版本为0，不能用评价对象冻结状态阻断正式训练。结构参数快照不是完整优化器与在线状态恢复点。

完整数据应含两模式、两初始化、两评价时点、三条件、四生成批次及四组的配对组合；文件数量以固定原始清单为准，不补造缺失。文件、配对、有限值或来源检查失败即停止有效性判定，保留失败，不改写原件。机械测试通过不等于效果成立。

## Result Boundary

本课程没有物理运动、搬运或伤害，仅两个外层初始化，不能证明真实蚁群生存、广泛未见环境适应性或相对普通MLP、纯规则的优势。同初始化训练前后对比补充训练作用的范围，不把两个模型当总体充分样本。合成张量的数学性质并不能证明其解释了前一课程失败。
