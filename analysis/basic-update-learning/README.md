## Question / Target Contrast

无危险基础课程留出世界中，学习接受决策相对全部跳过和全部接受的每候选平均焦点奖励差。

## Inputs and Data Freeze

输入批次 `20260926T094431-2`，225对候选、1426份原始文件，清单和数据身份已提交 `2e81171`。本次首次训练和结果计算之前登记分析计划，不读取既有危险诊断数据。

## Unit of Inference

训练6个整巢种子、留出2个，两个初始化条件配对。个体和候选相关，不把55条留出记录当55次独立重复，不做总体置信区间或显著性检验。

## Primary Analysis

校验散列、来源、身份、快照无写入与样本数。每只只用自身训练记录拟合141参数接受模型，固定200步，AdamW学习率0.01、权重衰减0.01、均方误差、梯度范数上限1，每25步及第0步保存。

所有模型完成训练后才读取留出标签。预测大于0接受，比较所选奖励差和全部接受奖励差，全部跳过差为0；以各世界全部候选为分母，分别报告两初始化条件。每个种子对两个条件的世界均值等权平均，空条件标缺失，不填0。另报预测均方误差、接受数、标签正负及相同数、选择造成的焦点和整巢交付差。

只有两个留出种子均优于全部跳过及全部接受，且至少一个世界选择导致正的焦点交付差，才满足设计的开发继续条件。未达标不修改本批阈值、轮次或样本。个体无训练数据则明确保留零模型，不以其他个体补齐。

## Exploratory / Sensitivity Analyses

仅记录个体样本量与训练损失，不选择成功个体、不挑最佳检查点，不追加超参数搜索。

## Assumptions and Diagnostics

单次随机延续最多64步，主轨迹全部跳过，学习选择只离线应用于固定分支；并未执行连续在线接受策略。人工残差扰动和简单第四接收器线索可能无法代表未见复杂环境。当前模型参数总量1607，最终MLP对照能力和预算匹配仍未完成。

## Result Boundary

本分析只检验简单课程的接受学习可行性及留出选择价值；既不是复杂环境迁移，也不是完整连续自训练收益或跨模型优势。训练损失下降、权重改变、门禁通过都不能替代这些证据。
