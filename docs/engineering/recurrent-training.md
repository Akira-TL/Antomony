# 单蚁循环记忆与条件写入试验

这是独立于原 `training.html` 会话的工程试验。训练服务同时提供 `/recurrent.html`；新会话和逐回合记录写在 `logs/recurrent-training/<会话标识>/`，不读取、覆盖原训练记录或研究数据库。

运行 `npm --prefix web run build` 后，用 `PORT=8770 bash scripts/training/start.sh` 启动，打开 `http://localhost:8770/recurrent.html`。若端口被占用，另选空闲端口。服务默认暂停；停止时用同端口运行 `PORT=8770 bash scripts/training/stop.sh`。旧训练页仍在同一服务的 `/training.html`，两页会话互不改写。

## 模型与时序

基础动作仍只有四个可训练连接，输出是否前进与连续转向。循环记忆改为 8 维隐藏状态；每步仅读取此前第 1、8、12、16 步的隐藏向量，不足的历史填零，回合开始清空。它不是把前 16 帧完整堆叠，也不直接读取过去的全局场景。循环矩阵因此为 8 × 32；旧版 4 维检查点与新版不兼容，只读对照工具会明确拒绝旧检查点。基础动作在后两个阶段及停止外部训练后锁定。

基础动作课程在回合奖励之外，对食物位于前方时的前进判断、食物位于后方时的停止判断和左右转向提供辅助训练信号。辅助目标只参与预训练损失，不在运行时覆盖模型输出。该约束避免前进偏置在持续训练中漂到临近停止阈值，使个体停在食物前。

第 `t` 步用当前观察和旧隐藏状态推理并执行行动；实际奖励、位移、碰撞等进入新的局部观察后，才计算下一步隐藏状态。循环记忆阶段**只记忆、不自修改参数**。条件写入阶段在本步反馈之后，由模型判断跳过或写入；写入只能改变本只蚂蚁本回合的三个临时动作修正量，分别对应前进偏置、转向增益、转向偏置。绝对值上限为 `0.30/0.15/0.12`，单次增量上限为 `0.025/0.012/0.012`。终止步不写入；隐藏状态和临时修正量在每回合开始归零，慢参数跨回合保留。

写入判断头与写入方向、幅度头在条件写入阶段接受回合末外部训练；判断头从写入之后的实际回报分配训练信号，每次请求写入计入 `0.02` 的训练代价。当前仍采用采样式策略梯度，尚未使用同状态写入/跳过的配对反事实训练，不能保证判断头学会正确时机。进入“停止外部训练”后可切换关闭、模型判断、始终写入三种方式；切换会重置当前回合，以便同一组慢参数作工程对照。

任务可选正常、转向扰动、感知偏差、混合任务。扰动回合在第 9 次行动前施加未向模型直接提供的正负 `0.25` 转向执行偏置，或从 `0.55` 至 `0.75` 弧度抽样的正负食物方向感知偏差；混合任务从无扰动与两种扰动中抽样。真实食物位置和奖励不随感知偏差改变，实际每步转向仍受原有上限约束。模型只能从自身行动后的局部反馈推断变化。两类信息素输入仍为零；感知偏差只是受控的适应任务，不能代表完整蚁群的循迹问题。

每回合保存慢参数、观察、隐藏状态、临时修正量、动作、奖励、写入判断和扰动值。页面展示失败回合与负奖励，不做结果筛选。它只用于确认动作、记忆、反馈时序与扰动隔离；是否提高效率须在相同任务和随机种子下比较关闭、模型判断、始终写入及只记忆条件，不能由本页单独得出。

只读的固定种子工程对照入口：

```bash
bash scripts/training/compare.sh logs/recurrent-training/SESSION_ID/episode-000123.npz --first-seed 1000 --seeds 30
```

命令对同一检查点分别执行正常、转向扰动与感知偏差任务，使用相同食物种子比较三种写入方式，并输出全部逐种子原始结果及有符号差值。失败回合计入 96 步上限，不筛选不利于模型的种子。该输出仍只是开发诊断；正式优势声明需另外固定研究设计并由 `akira-research` 验证。
