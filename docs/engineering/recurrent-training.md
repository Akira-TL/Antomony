# 单蚁循环记忆试验

这是独立于原 `training.html` 会话的工程试验。训练服务同时提供 `/recurrent.html`；新会话和逐回合记录写在 `logs/recurrent-training/<会话标识>/`，不读取、覆盖原训练记录或研究数据库。

运行 `npm --prefix web run build` 后，用 `PORT=8770 bash scripts/training/start.sh` 启动，打开 `http://localhost:8770/recurrent.html`。若端口被占用，另选空闲端口。服务默认暂停；停止时用同端口运行 `PORT=8770 bash scripts/training/stop.sh`。旧训练页仍在同一服务的 `/training.html`，两页会话互不改写。

## 模型与时序

基础动作仍只有四个可训练连接，输出是否前进与连续转向。循环记忆由 4 维隐藏状态、观察到隐藏状态矩阵、隐藏状态到隐藏状态矩阵、偏置和动作修正头组成。当前可训练参数为基础动作阶段 4 个，循环记忆阶段 92 个；基础动作在循环记忆阶段及停止外部训练后锁定。右侧显示各组真实值、最近回合末变化和当前冻结位置。

第 `t` 步用当前观察和旧隐藏状态推理并执行行动；实际奖励、位移、碰撞等进入新的局部观察后，才计算下一步隐藏状态。没有运行期参数自写入。隐藏状态在每回合开始归零，慢参数跨回合保留。该版本是**只记忆、不自修改参数**的对照模型，不把隐藏状态变化称为自训练。

任务可选正常、转向扰动、正常与扰动混合。扰动回合在第 9 次行动前施加未向模型直接提供的正负 `0.25` 转向偏置，实际每步转向仍受原有上限约束。模型只能从自身行动后的局部反馈推断变化。当前课程仍直接给出可见食物相对方位，两类信息素输入为零；它不能代表完整蚁群的循迹任务。

每回合保存参数、观察、隐藏状态、动作、奖励和扰动值。页面展示失败回合与负奖励，不做结果筛选。它只用于确认动作、记忆、反馈时序与扰动隔离；是否提高效率须与冻结动作、无记忆以及后续条件写入模型在相同任务和随机种子下比较，不能由本页单独得出。
