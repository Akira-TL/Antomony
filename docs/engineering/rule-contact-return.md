# 规则组接触处理与返巢修正

## 发现

原基础检查中规则组在四个食物世界仅交付4/64份，不是公平比较自训练优势的充分对手。读取已保存记录后发现，9603世界拾取3份却无交付；确定性完整回合测试再次出现同一失败。

进一步记录表明，携食个体0在302个携食步中仅前进19步，而归巢梯度从未低于控制器的有效阈值。控制器将任何接触都转换成12步原地转向，包括正常拥挤产生的接触；局部方向因此被反复压制。

只在诊断中屏蔽接触输入，9603世界即可交付16份。该诊断不改变物理碰撞，也未给控制器隐藏坐标。原输出：`logs/rule-contact-20260926T103944-2.jsonl`，基于 `193b6a6` 的控制器及本次新增诊断入口。

## 修正与验收

现在有有效局部梯度时优先按梯度行动，并清除尚未完成的盲目原地转向；无可用方向时保留原接触避让。信号选择、阈值、随机探索、速度与转向上限、物理碰撞均不变，规则组仍完全不使用神经网络。

两个局部测试先失败再通过：接触不能覆盖有效方向；新获得信号须退出盲目转向。原9603完整世界修正后交付16份，输出：`logs/rule-contact-20260926T104108-2.jsonl`。四个既有开发世界均完成至少一次交付的回归条件，加上直线返巢和对照接口测试共19项通过。

UV_CACHE_DIR=/tmp/mathhackson-uv-cache bash scripts/diagnostics/rule-contact.sh
UV_CACHE_DIR=/tmp/mathhackson-uv-cache uv run --no-sync pytest \

## 边界

这是开发环境内的控制逻辑缺陷修正，不是正式模型效果研究，也不代表四个世界全部达到神经组速度。局部梯度仍可能有高峰，存在强梯度但不可通行的墙时也可能需要其他处理；当前往返训练场没有内部墙，不能把本修正外推为任意迷宫通行保证。

下一步重新固定规则组基础资格检查，不继续沿用旧规则成绩。完整无线索探索、预算返回、相近模型规模及同能力对照仍需核对。
