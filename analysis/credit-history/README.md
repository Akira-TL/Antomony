## Question / Target Contrast

在每4步判断的前提下，最多保留16步动作相对仅当前4步，是否产生更多有实际收益的候选？逐世界比较同状态接受一次减跳过的焦点奖励和交付，并计算两配置的配对差。

## Inputs and Data Freeze

数据提交 `2650684`，批次 `20260926T180337-2`，556文件、四世界108条记录。已见父轨迹数量和交付汇总，不称完全盲化；尚未计算两配置候选收益。原始结束元数据缺失已在实施记录披露，必须通过完整性审计后才使用。

## Unit of Inference

整巢种子19901、19902。各配置30、24条，对应54个共同状态；配置、个体、时间点相关，不将108条记录当108次独立实验。

## Primary Analysis

先审计556文件、来源模型和冻结协议、1758帧、272组参数快照。两配置父轨迹逐帧一致、基础与残差未变；候选身份、观察、隐藏状态、修改前动作分布及跳过分支必须匹配。零候选必须没有分支差异；实际接受参数必须等于合法提案结果。失败则不输出有效效果结果。

分别描述各世界奖励及焦点/整巢交付的接受减跳过差，保留正、负、零数及均值；正负计数用1e-6浮点容差，均值不截断。继续条件沿用冻结设计：两种子均有正收益、新正数均不少于旧、各世界新减旧奖励和交付均值非负、至少一世界奖励严格提高、且新配置至少一次真实焦点交付改善。不得用整巢平均掩盖某一种子的退步。不做显著性检验。

## Exploratory / Sensitivity Analyses

报告非零候选数及配置差的正负零分布。没有额外窗口、种子、学习率或归因范围搜索。

## Assumptions and Diagnostics

父轨迹全部跳过，候选只在分支内接受一次，不是连续学习。54个状态不能表征全部环境；采样间隔16步只决定评价时点，不改变每4步判断。审计验证记录一致性，不声称独立重建全部环境或因果机制。已用短合成世界测试参数改写、缺帧、归因范围、观察和跳过分支不一致时拒绝分析。

## Reproduction

## Result Boundary

本批没有支持扩大动作保留即可增加有益候选；按既定规则停止本路线，不搜索8/32/64、不追加种子或接受训练，选项保持默认关闭。仍保留用户要求的四步判断，不把失败解释成应该退回十六步判断。

机械例子中可以归因后到奖励，不等于当前环境就会产生可用收益。只有两个开发种子和54个抽样状态，不能推断所有较长归因机制无效，也不能单独识别失败是候选表达能力、反馈内容还是状态覆盖不足。下一步优先核对候选能改变的实际行动与任务目标是否对应，而非继续窗口搜索。本轮不是连续自训练、生存或未知环境适应的检验，不更新8774。
