# 无食物预算返巢诊断

## 执行前固定

首轮群体评估多数场景搬完即结束，不足以检验探索预算返巢。此诊断不新增训练、不选最好快照、不注入合成回巢路径。使用 `20260926T070617-2` 的预算训练前、预算监督后和第8回合群体模型，检查点散列另存。

环境种子9301至9304，8只独立模型，保留原出生、碰撞、预算160+160、512步上限及固定信息素释放。食物库存从初始设为零，因而没有食物气味、拾取或交付；仍保留固定步数与个体耗尽终止，不能因无食物立即结束。模型只看到真实局部信号和自身预算。

三个阶段分别按已固定的方向采样方式运行，共12个世界；奖励后模型再遮蔽两种信息素运行4个世界。每组世界隔离，使用相同种子与动作采样发生器。无权重更新。全部实际轨迹、预算和返巢事件保留。最多16个世界，结束后不自动追加试验或训练。

主要看有多少不同个体真正耗尽预算后返巢，而不是把重复次数当成功个体数；同时报告返巢次数、首次返巢前最大离巢距离、耗尽数。必要时由实际行动重建世界检查事件和预算补给，不使用全局方向指导行为。

该诊断是看到原评估覆盖不足后追加的开发试验，并非事先注册的确认性实验。若只在短距离停留后进入巢穴，不能称学会远距离循迹；若遮蔽信息素也有同样表现，需要降低对循迹机制的解释。

入口：`bash scripts/training/colony-return-probe.sh`。
