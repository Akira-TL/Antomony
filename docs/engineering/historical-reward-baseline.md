# 历史奖励基线试验选项

## 实现边界

`AdaptationConfig.historical_baseline_rate` 默认为0，所有既有实验配置与8774不变。开启时只允许 `observed-window`，不调用未经校准的价值输出。

窗口内先计算既有折扣回报 `G_t`，用于更新的权重为 `G_t - b`。`b` 来自该个体以前已处理的窗口；当前提案接受或拒绝后才更新为 `(1-rate)*b + rate*mean(G)`。初始基线为0，当前窗口的动作、终止长度或结果不参与选择本窗口使用的基线；不按当前窗口均值做中心化。

这只是标量历史均值，不是状态价值预测器，不保证降低当前任务的方差。处境突然变化、窗口提前终止或回报非平稳时可能失配。它不提供应向哪走的标签，不改变奖励定义、动作模型、接受网络、参数上限或方向采样。

## 依据与限制

策略梯度可以减去不依赖当前所选动作的基线；合适的基线用于降低估计方差。参见[OpenAI Spinning Up的基线推导](https://spinningup.openai.com/en/latest/spinningup/rl_intro3.html#baselines-in-policy-gradients)，2026-09-26核验。该依据不保证这里的历史标量合适，也不弥补有限窗口截断、缺少状态价值和多蚁环境变化的问题。

工程核对确认当前惩罚符号没有反转：负回报乘以负对数概率梯度，在下降步骤中压低已采样动作概率；但一个受伤窗口中的多种动作可以共同得到负权重。新增选项用于独立检验整体奖励水平的影响，不能宣称现有趋险根因已经确定。

## 个体、复活与保存

基线与累计窗口数属于个体状态，不共享。复活保留、检查点写入、分支副本独立复制。开启选项的检查点缺失或损坏状态时拒绝载入；关闭选项的旧检查点仍兼容。分支仅复制已处理历史，不能吸收父轨迹待定窗口或分支未来。

保存参数与基线不等于完整训练恢复；尚未保存的计算图、窗口缓冲与世界状态仍按原有能力边界处理。

## 验证与下一步

沿已有反馈、提案、决定与保存载入接口测试：手算回报、当前窗口隔离、个体隔离、分支复制、重启保留、损坏检查点拒绝、默认关闭逐提案一致。单步恒定反馈的人工例子中，吸收过往同值反馈后不再产生虚假的随机梯度；这是计算合同测试，不是危险环境有效性证据。

新选项未接入正式对照或验收页。效果对照须另行固定唯一非零速率、预算、新世界种子、比较和停止条件；不从危险诊断结果选择速率或接受阈值。
