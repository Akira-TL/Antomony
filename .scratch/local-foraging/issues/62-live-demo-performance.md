# 实时演示流畅度

## 验收范围

- 每个仿真步只生成一次完整展示帧，不为记录与发布重复采样。
- 行动后的局部观察同时供在线反馈和展示使用，不改变观察时点。
- 浏览器不重复上传同一时点的信息素纹理，并按实际帧间隔连续插值。
- 展示帧通过同源WebSocket长连接主动推送，不再用短周期HTTP轮询。
- 降低三场景并行渲染开销，不改变模型步、四步更新或环境物理。

## Answer

服务端复用行动后观察，并把同一份记录帧直接发布；每个WebSocket客户端只保留最新待发帧。页面不再轮询，按真实到达间隔插值，跳过同一状态的纹理解码，并降低三场景像素比和阴影尺寸。8项定向测试与前端生产构建通过；公网nginx实际返回101，短测显示三组单步约111毫秒，此前页面观察值约203毫秒。
