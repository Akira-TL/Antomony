# 陌生信号的受限在线更新接口

## 为什么限制修改范围

首轮整网奖励课程提高近巢返巢，但缩小探索范围并降低前进比例。此处采用一个可撤回的开发候选：保留已经训练的基础信号、记忆、方向读出及82参数动作底座；只开放第4至8接收器的两个40参数输入模块。它限制遗忘的范围，不保证能处理全部新环境，更不是最终架构已定案。

## 时序和反馈

`act` 用当前参数输出并采样方向，由冻结动作网络决定前进和转向。行动实际发生后，只把该个体真实奖励传入 `feedback`。每16步或终止时，`propose` 根据折扣回报与冻结价值基线形成策略梯度提案，不写参数。`resolve` 分别接受或拒绝相对信号与绝对强度两个模块；接受才通过已提取的 `FastResidualParameter` 写入80维残差，下一次推理读取新参数。无需下一步位置预测标签。

先用无动量的随机梯度下降，学习率0.02，单次增量L2范数不超过0.05，总残差L2范数不超过1，保存最近8次非零修改。分模块拒绝后重新检查总界限，不以缩放全部旧权重的方式改变被拒绝模块。所有数值是待检验的工程起点，不是已验证的最优设置。价值基线冻结可能导致估计偏差或高方差，不能假设一定适用于新场景。

候选包含后到奖励均值/最小值、梯度范数、陌生接收器响应等已发生证据，供后续接受判断训练；当前接口本身没有学会判断。始终接受、始终拒绝只是比较条件。每个体有独立模型、副本动作底座、隐藏历史、随机数和残差记录，不跨蚂蚁传播梯度。

终止之后必须先完成该轨迹的反馈和接受决定，再允许重启。重启保留参数、清空隐藏状态；这为后续死亡经历更新再继承提供入口，不等于已经实现整个代际实验。

## 保护与边界

当陌生输入全零、比较相同历史时，即使陌生模块已有更新，旧基础输出保持完全一致；这一点由测试验证。实际遇到陌生信号会改变路径及隐藏状态，因此不能把此不变量扩大成“后续所有行为必定不变”。

五项工程测试同时核验候选不写入、拒绝时参数和残差历史不变、单模块冻结、个体隔离、基础动作不变、因果时序、非零保存恢复及累计范数范围。模型NPZ与残差NPZ独立保存，不覆盖旧检查点；保存不包含完整世界和随机发生器恢复，不能声称任意步精确续训。

下一门槛：在已知基础能力相同的个体中，对陌生局部响应下的“接受候选”和“跳过候选”做固定预算诊断。只有存在有益与有害候选，且已发生的证据有区分信息，才值得训练接受模型。普通规则对照不创建神经网络；最终同规模MLP与复杂场景对比仍待正式设计和登记。
