# 贯通离线课程的动作特征

在现有采样、分区读取、逐个体拟合中增加显式可选配置，不改变旧课程默认值或旧研究产物。

## 验收

- 38维动作特征在未来分支运行前取得，格式有独立版本；读取拒绝缺失、错误长度、非有限值和未知版本。
- 相同种子启用特征记录后，父轨迹、候选及配对结果不变；旧采样不新增样本字段。
- 新课程读取178维，旧课程保持140维；新拟合仍按个体和训练世界隔离、定期保存检查点。
- 工程测试不登记为新基础训练成果，不解除生存配置对旧接受器的限制。

## Answer

新增显式采样开关和课程输入配置，记录先于未来分支，带版本读取及逐个体拟合已贯通。旧默认、未启用时的样本格式和既有生存资格限制保持不变。测试覆盖相同种子轨迹/分支不变、坏格式拒绝、新旧输入读取、个体分离、定期保存与重载。正式新课程未采样或训练，详见 `docs/engineering/action-aware-decision.md`。
