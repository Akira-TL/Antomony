## Question / Target Contrast

同一无危险扰动状态下，64步反馈候选相对16步反馈候选在后续最多64步的焦点奖励与交付差。

## Inputs and Data Freeze

批次 `20260926T101927-2`，28条记录、14个预期共同状态；588文件清单及数据身份提交 `924ff40`。当前只知道主轨迹计数相同，尚未计算候选配对收益，首次结果前登记计划。

## Unit of Inference

两个整巢种子，逐状态配对；同巢点相关，不把14个状态当独立重复，不做总体显著性判断。

## Primary Analysis

先核对完整散列、来源、两协议只差反馈窗口、全部压缩主轨迹逐行相同、观察与记忆相同、快照保持初始值、跳过和恢复参照完全相同。任何匹配失败都停止解释。

按种子描述每窗口接受减跳过的奖励、焦点及整巢交付差，再报告64减16的配对差；保留正负相同数、均值与范围。奖励相同容差1e-6，交付容差0，空数据为缺失，不填0。另描述窗口反馈全零次数、零候选数及增量范数；全零指平均与最低奖励均为0，本无危险课程奖励非负。

两个种子的64减16平均焦点奖励都为正，且至少一个种子焦点交付配对均值为正，才满足选择64步的开发条件。不是最终自训练或长期策略效果判据。
