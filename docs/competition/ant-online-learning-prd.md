# 蚁群在线自学习：比赛版产品需求文档

状态：2026-09-26 的比赛表达与演示目标；不是研究设计冻结稿，也不代表下述目标全部完成。

## 一句话定位

让每只蚂蚁在行动后利用自身反馈，判断是否需要修改自己的模型，再用修改后的模型继续行动；在持续变化的环境中，检验这种**有选择的在线学习**能否比不更新或每步都更新更有效。

评委应看见的不是参数曲线一直变化，而是同一环境干预下，蚂蚁能否及时适应持久变化，又不因短暂干扰把原有能力学坏。结果可以为负，现场不预设神经组获胜。

## 核心亮点与可用话术

**15 秒介绍**：我们研究神经网络能否在运行中决定“这次经验值不值得写进自己”。蚂蚁每一步先行动、再接收反馈，随后选择更新或跳过；我们用同步干预的独立环境，对比冻结模型、持续更新模型和普通规则蚁群，直接展示收益与代价。

**三项亮点**：

1. **学习发生在行动循环内**：`感知 → 推理 → 行动 → 反馈 → 判断是否更新 → 下一次推理`。更新后的参数实际参与后续决策，而非训练结束才替换模型。
2. **学习“何时不学”**：短暂噪声不一定值得写入，持久规律变化则可能需要适应。模型的更新判断与行动能力分开检验，记录每次接受、拒绝及行为后果。
3. **把能力变化放进可观察的世界**：每只蚂蚁保留独立模型；两组环境隔离、干预同步。墙、外力、资源和信号变化后，同时看行为、参数和带符号成绩差，不只展示成功片段。

**关于长期愿景的准确表述**：这一机制可以在有反馈和计算资源时反复运行，不要求为每次新经历永久保存一份完整训练数据；但模型容量、遗忘、计算和存储仍有界。将类似机制用于大模型的持续知识学习，是待研究方向，不是本蚁群实验已证明的“通用人工智能雏形”。

## 受众与要回答的问题

受众为神经网络赛道评委，以及现场监督训练的项目成员。关键问题是：在初始行动能力相当、传感输入相同的条件下，面对未用于基础训练的持续、短暂和周期变化，**学会选择更新时机**能否带来稳定、可复现的行动或搬运收益？

不把“神经网络参与了动作”“参数确实变化了”“单次演示搬回更多食物”单独当成这一问题的肯定答案。

## 产品路径与范围

| 阶段 | 体验或系统行为 | 当前状态与验收重点 |
| --- | --- | --- |
| 单蚁动作基础 | 输入身体坐标下的期望方向，模型决定前进与转向；后续训练冻结基础动作参数 | 已有三个独立训练初始化通过无障碍方向跟随开发验收；未由此证明寻食或归巢 |
| 信号到方向 | 以少量有选择性的局部接收器观察食物、离巢、归巢及复杂混合信号；信号层形成表示，方向层给出期望方向，冻结动作模型执行 | 目标架构，尚未完成端到端验收；不直接给隐藏食物或巢穴的全局坐标 |
| 往返搬运 | 出巢探索、拾取、凭局部信息返巢交付，再利用留下的线索重访；信息素释放、衰减、拾取和交付由世界规则执行 | 旧 3D 蚁群演示已有两类信息素及真实搬运；它不是上述新分层模型的往返训练成果 |
| 有选择的自更新 | 行动后取得局部反馈，形成有限的候选修改，再由学习到的判断接受或跳过；被拒绝时不改行为参数 | 独立方向扰动探针已实现并训练判断，但尚未接入完整信息素搬运模型 |
| 复杂环境验证 | 同步加入减速、周期变化、障碍或可混淆的新信号，对比适应收益、负迁移和资源代价 | 正式对照与确认性实验未完成；不能从方向探针外推到复杂蚁群 |

基础接收器可对常见来源呈现明显响应；复杂来源允许同时激活多个接收器。系统不把来源类别或应该趋近、避让的答案直接塞进观察值。模型需要从行动后果中区分组合信号的意义。普通规则组不使用神经网络；神经组个体之间不共享参数、梯度或优化器状态，只通过环境信号相互影响。

## 最短现场演示

1. 在现有 3D 页面用同一种子开启隔离的双场景，展示两组蚂蚁持续行动与搬运；先说明这一步演示的是世界和可视化，不是最终自学习优势。
2. 同步放置障碍或改变外力，观察真实行为、搬运量和有符号差值；随机种子由现场选取，不预设胜者。
3. 展示独立方向探针中，同一动作基础上的“不更新、始终更新、简单规则接受、学习判断”四种结果，并指出学习判断确实会跳过修改，但尚有退化条件。
4. 若集成后的信号往返模型尚未完成，只明确标记为下一阶段，不播放能被误认为该模型实时运行的旧演示。实时服务失效时使用标明来源的既有实验记录，不把记录回放说成实时推理。

本演示不依赖云端推理，不修改本机网络或代理配置。现场界面是验收控制面，不以增加展示页面代替模型训练与验证。

## 比较与验收

**工程验收**：每只个体独立参数与更新状态；动作基础在信号训练中冻结；被拒绝的候选不改行为参数；两侧世界状态隔离且干预同步；信息素释放由代码控制；模型更新日志能关联到后续行为；两种信息素颜色可区分；记录真实负差值与失败种子。定期保存权重和必要的优化器状态，以便比较能力演变；若未保存完整环境与历史，不宣称可从任意一步精确续训。

**研究验收**：先固定训练、开发和从未用于选择模型的确认场景，再对比无神经网络规则蚁群、同等输入与容量的普通多层感知机、冻结网络、始终更新网络和有选择更新网络。对相同初始能力和预算进行配对，分别报告方向误差、有效前进、拾取、交付、每百个体步搬运量、参数写入次数、计算时间与存储占用。报告全部预定种子和有符号差值，不能只凭局部误差下降宣称运输效率提高。何时更新的效果还需与**相近更新频率的随机接受**比较，排除“仅因少更新而受益”。正式实验按科研流程另行固定设计；开发探针不替代该实验。

## 已知结果与声明边界

当前方向更新判断探针在每 192 步平均实际写入 43.94 次，始终更新组写入 192 次；它能同时接受和拒绝。但方向误差相对不更新组，在持续正、负偏转下分别改善约 1.10°、1.42°，在正常、短暂扰动和周期变化下分别恶化约 0.27°、0.23°、0.28°。有效前进的变化很小，本探针没有食物搬运。训练判断的分类准确率约为 64% 至 67%；这不是可靠掌握更新时机的证明。上述是留出**开发**条件，不是独立确认性结论，完整依据见[更新判断结果](../engineering/direction-gate-results.md)。

“实时”在这里指运行中按行动反馈进行在线更新，**不是**已达到固定时延的硬实时保证。“循环”指过程可反复执行，**不是**容量无限、无遗忘或稳定收益无限。“无需多余参数存储”不能作字面承诺：权重、更新判断网络、优化器状态、个体历史和检查点都占用资源。准确亮点是**不必为了每一次在线更新都永久保留完整过去数据集**，其实际成本仍需测量。将此能力迁移到大模型、把新知识稳定写入内部参数以及接近通用人工智能，均未在本项目验证。

## 下一项最有价值的工作

保持现有动作基础和已训练更新判断不变，先补“相近写入频率的随机接受”低成本对照，弄清判断网络是否真的学到选择时机；若没有净收益，不扩大自更新网络。与此同时把局部信号经方向层接入冻结动作基础，并完成单只蚂蚁的拾取与交付闭环。两条证据都成立后，才投入复杂信号和整群比较。
