# 冻结动作能力后的信号判断与往返训练

## Destination

确定一份可以交给实现的训练方案：信号层学习局部信号表示，方向层根据表示及记忆生成期望方向，已训练的行动能力完整冻结，完成单蚁探索、发现食物、归巢和再次搬运。明确输入接口、信号规则、课程顺序、验收条件，以及后续条件自修改的范围和进入条件。

终点是关键决定有依据且相互一致，不是本轮训练出模型或证明自训练有效。

## Notes

- 用户明确调用 `wayfinder`，并同意先确定信号、固定释放规则和冻结模型接口。当前逐条解决规划问题；本地图没有执行覆盖授权，不继承旧蚁群首版地图的快速实现例外。
- 工程入口为 `ask-akira`；对话决策须加载 `grilling` 与 `domain-modeling`。研究条目须加载 `research`，原型条目须加载 `prototype`；形成正式科研设计或效果主张时由 `akira-research` 路由。
- 本仓库 tracker 为本地 Markdown，规则见 `docs/agents/issue-tracker.md`。当前串行处理；状态文本不提供多 Agent 互斥。
- 已确认约束：原动作模型决定是否前进和转向量；信息素由代码固定释放；单蚁预训练；每只蚂蚁参数独立；归巢只读局部信号，不提供全局巢穴方位。
- 用户提出的信号范围包括离巢标记、食物信息素、食物源气味和危险信号。信号源的类别与接收器如何表示它们是不同问题，不能把显式类别通道等同于模型自主识别类别。
- 食物有限范围内的递减信号是已确认的场景要求。探索激励与随机性来源的讨论分别记录在对应条目中，不把奖励目标误当作已确定的执行算法。
- 用户已报告原地打转与无法归巢，作为设计修改依据，不再要求复现。上一轮错误连接已撤回；8773 已停止。第 2570 回合基础检查点和历史记录保留。
- 不以代码测试、合成误差或教师轨迹误差代替真实往返能力验收。旧结果不能给新结构作效果背书。
- 原 V2V 只读；既有未提交研究草案与数据库保持原状。不修改网络、代理、nginx 或 ForgeRelay。

## Not yet specified

信号表示与完整往返课程确定后，才具体化需要多长的记忆、如何处理多源交叉和暂时不可辨认的方向；不预设扩大参数规模能解决这些问题。

训练接口与可观测反馈确定后，才具体化条件自修改所需的参数分组、训练样本及延迟收益分配；不沿用已否定结构的写入头作为既定设计。

## Out of scope

- 本轮实现新模型、启动训练、重建前端或让用户试用未训练控制器。
- 重新训练原基础动作能力，或者让新增信号层再次输出独立停走指令。
- 让模型学习信息素释放策略，或者用规则导航替代神经组的信号判断。
- 此时直接开展完整多蚁、规则组、多层感知机与自修改模型的正式对照。地图需留下该研究的进入条件，但不把比较结果当作本轮终点。
- 新增全局巢穴坐标、远距离食物方向或其他答案型行动输入。
