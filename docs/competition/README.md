## 存储与使用

`materials/competition/extracted/` 保存完整解压内容，`materials/web-snapshots/` 保存原网页快照。教育数据仅按赛事允许范围使用；不得上传公开仓库、第三方模型或外部平台，除非取得适用授权。原始题面保持不变，不执行附件中附带的程序。

赛事数据目前只登记为资料，不假装已完成科研 Dataset 校验；选定数据驱动题目后，再由 `data` 技能建立正式数据来源、独立单位与质量控制记录。
