# 如何完整保留第 2570 回合的动作能力与输入语义？

## Question

核对基础检查点、配套回合记录和原推理路径，确定已学会能力究竟依赖哪些参数、隐藏状态更新及运行模式。旧接口中的方向和距离分别表达什么？新信号层应该输出什么，才能保留这些语义而不新增停走判断？

所需依据是实际文件与接口契约，不是要求用户重复演示失败。特别核对方向单位长度、身体坐标变换、距离槽、反馈信息及冻结边界；不得只复制四个参数就默认完整保留原能力。当前不修改实现。

## Answer

检查点与来源摘要一致。四连接动作之外，已保存的循环记忆及动作修正实际参与了该历史回合的推理；完整接口还依赖目标距离、目标进展、原奖励反馈及确定性运行阶段。仅固定四个动作参数并替换距离或反馈，不能视为原能力原样保留。

事实、原始来源、归一化含义和未知范围见[接口核对记录](../../../docs/engineering/frozen-action-interface.md)。未启动训练或行为复现。事实调查已完成；冻结范围与局部目标接口另建对话决策条目，不代替用户回答。
