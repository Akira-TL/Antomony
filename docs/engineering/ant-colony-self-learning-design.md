# 蚁群自主学习控制：训练方式候选

状态：2026-09-25 的工程与文献核对结果；尚未冻结科研设计，尚未执行本方案的训练或效果实验。本文不替代 `RESEARCH.md` 中另一项选择性回退研究草案。

## 要回答的问题

目标不是让参数持续变化，而是检验每只蚂蚁能否仅凭当时可见状态与随后到达的反馈，后天学会在有益情境中修改自己的预测模型、在有害或无信息的情境中跳过，并因此改善后续决策。需要分别回答：

1. 动作后果预测是否因选择性更新而更准确？
2. 预测改善是否改变了候选前进方向的排序？
3. 这种改变是否在独立场景中提高搬运效率，而不只是降低训练误差？

三问不能用同一指标代答。当前 `Brain` 的预热标签由随机净空公式构造，在线时每次未冻结的行动都更新输出层；网络的 8 维输入没有两种信息素的浓度或方向差。故当前“预热误差下降”和“在线更新次数增加”都不是自主决定学习时机的证据。

## 只读参照与证据边界

原 V2V 在提交 `aab9767615121a1bb517a89802e0ab0af306f12c` 中提出：先固定读取旧参数完成本轮前向、形成预测和学习控制动作，再提交参数变化；学习控制路径只能根据实际执行动作及后到反馈获得信用，不能被同一轮由自己放大的修改立即训练。`docs/research/v2v-primitive-learning-signals-2026-08-31.md` 第 27 节及 `docs/research/v2v-explicit-hypotheses.md` 的 H-023 给出这一边界。

## 推荐的最小训练结构

每只蚂蚁保留两条独立参数路径：动作后果预测器 `P` 与学习控制器 `G`。二者属于同一个体，不在蚂蚁之间共享权重、梯度或在线经验。普通规则组不构造 `P` 或 `G`。已有 `FastResidualParameter` 只提供可逆参数执行能力，不自动决定更新是否正确。

`P` 在给定局部观测和候选动作后预测下一次自身位移、接触及其可信程度。`G` 看到当前预测与实际反馈的差异、近期误差变化、当前候选更新的大小、接触与停滞等自身可见量，输出本轮参数修改强度 `g`，范围为 0 到 1；`g=0` 表示跳过。它不看场景编号、未来位置、隐藏食物坐标或“这次是短扰动”的标签。

一次事件的因果顺序固定为：

```text
用本轮开始时的参数推理并保存预测
→ 执行动作、取得本轮实际位移与接触
→ 根据预测差异形成候选参数增量，但尚不写入
→ G 根据当时可用的证据决定 g；g=0 则跳过
→ 完成本轮所有输出以后，才写入 g × 候选增量
→ 下一次推理读取新参数
→ 后续真实反馈到达后，评估此前的更新动作并训练 G
```

训练 `G` 的核心信号不是人工给的“正确门值”，也不是本轮误差大小，而是**这次更新对后续新样本的预测是否有益**。在线记录旧参数与更新参数对同一后续观测的两个预测，比较它们面对随后实际结果的损失。对已实际提交的修改，可以定义候选信用为 `下一样本的旧参数损失 - 下一样本的更新参数损失 - 修改成本`；正值支持当时的更新动作，负值抑制它。修改成本的尺度必须只在开发场景中选择，不能依据确认结果追调。跳过的候选可保留影子预测供审计，但不得冒充已执行动作取得学习信用。由于当前输出层是线性读出，候选增量对下一次预测的影响可直接计算，不必引入完整 V2V 计算块或跨时间反向传播。

这项同一样本比较只能识别**预测更新的局部价值**，不能证明如果蚂蚁当时选择另一方向会搬回更多。学习 `G` 的初期应固定行动策略或使用只读规则轨迹，使“更新是否有用”不与“更新改变了所访问的状态”混为一谈。正式闭环行为评价另行进行。代码侧仍可限制单次修改范数、非有限值和近期残差容量；这些是物理稳定界限，不是外部替模型判断某次经验有无价值。

## 分阶段训练和最小对照

1. **记录期，不训练新门。** 给每次行动保存可见观测、更新前预测、候选增量、门输出、是否真实提交、下一次结果，以及旧/新参数对同一后续样本的预测。先验证严格“先预测、后反馈”、冻结时零修改、跳过时参数字节不变、不同个体参数隔离。记录不包含环境隐含真值。
2. **基础预测期。** 用本模拟器真实执行的局部行动与接触作训练数据，按世界种子和墙/扰动配置隔离训练、开发、留出场景；不再以随机净空公式的练习误差作为唯一预热合格条件。每只个体独立初始化和更新，不能复制一个已经训练好的共同在线模型冒充独立学习。
3. **学习时机期。** 构造无变化、短暂污染、持续物理变化、拥堵及两者叠加的连续经历。训练时不把情境名称交给 `G`；让它根据后到的局部更新信用，学会何时增大学习、何时减弱或跳过。最初必须保留有界探索机会，否则一旦恒为零便永远得不到“更新可能有益”的执行证据。学习门自身的更新只能在其动作完成、后果到达后发生，不能用本轮门值同轮放大自己的训练。
4. **行动转移期。** 保持已学学习时机，检查预测变化是否真实改变候选方向排序。若目标是让模型自主使用两类信息素，必须再把两通道的可达方向信号和信号对比度加入其可见输入；只学运动后果的 `P/G` 不会凭空学会寻食策略。“是否让模型决定方向”需要独立的行动收益问题，不能用预测损失直接训练成另一个门。

行动收益的下一候选是：先保持规则意向不变，检验更准确的后果预测能否减少接触和无效位移；只有这条路径确有作用，再训练任务条件化的方向价值。携食阶段可用后续实际回巢进展和交付作为反馈；寻食阶段以实际发现资源、重复绕行和有效探索经历形成延迟结果，不能把远处隐藏食物坐标当正确转向标签。相关行动需要保留有限资格，结果到来后才分配信用。“是否由学习策略取代规则方向”还需单独学习与评价，不能让学习门 `G` 同时充当行动门。

每阶段至少比较：始终不更新、每步更新、固定误差阈值更新、与学习门更新次数匹配的随机更新、学得的更新门。所有神经条件使用相同初始容量、数据预算和允许修改的参数集合。先看独立留出场景上的下一次预测损失、短扰动后的恢复、长期变化后的适应、旧能力保持与更新次数；之后才看搬回量、每百个体步接触、停滞、路径效率和计算开销。以独立世界/种子为重复单位，不把同一世界内 32 只蚂蚁当作 32 个独立实验。

## 不可跳过的难点与停止条件

- 第一次异常本身未必能区分短暂噪声和持续改变。若可见历史相同，就不能要求模型在首次事件时完美判断；应测发现差异所需的经历长度，而不是泄露变化标签。
- 后到的单条反馈没有“没更新时真实会如何行动”的行为反事实。早期的同一样本影子预测只用于预测门；搬运优势必须由独立世界、固定干预与预先确定的评价规则检验。
- 若学得的 `G` 在留出场景恒开、恒关，或只记住训练时的情境顺序，就没有学会有条件的自主更新。
- 若预测损失下降但方向排序和搬运不改善，应分别报告“预测更新有效、行动收益未证实”，不能改写为模型优势。
- 若新训练方案无法在本机现场启动与稳定运行，保留已有演示，不以预录优势画面替换实时对照。
