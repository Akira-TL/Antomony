# 核对持续伤害扣分如何影响候选

用户指出非即死陷阱应在持续受伤时大量扣分。核验不是只看奖励字段，而要看惩罚经过候选归一化后是否改变实际行动分布。

## 验收与结果

- 真实环境已逐步扣分；时序分析另行登记，不把延迟猜测当根因。
- 同观察同行动、零基线、每步负0.08与负8的16步测试：梯度放大100倍，行动分布数值一致、参数步长未放大超过1%。
- 逐参数近乎相等的最初断言失败，保留数值差异说明；测试实际作用而非宣称逐位相同。
- 7项候选测试通过。未修改运行惩罚、触发时机、模型或旧验收页。
