# 混合信号中的可辨别差异由什么承载？

## Question

用户已选择混合感知并新增独立信号处理层。不同信号源是产生稳定但不标注语义的多维响应特征，在接收器处叠加；还是只提供总强度，主要依赖时间与空间变化辨别？

必须区分连续响应特征与直接给定类别编号。若存在产生相同观察历史、却要求不同动作的情形，应承认不可辨别，而不通过加网络层假定信息可恢复。响应维度、混合与归一化方案在这一取舍后由调查支持。

## Answer

用户选择“多维混合响应，不给类别标签”。不同类型的信号源保留稳定的可观测响应差异，接收器获得叠加后的响应，信号层学习其任务意义；不直接输入食物、危险等类别名称或编号。响应维度、源特征及混合后可辨别条件仍由信号规则调查核定。

用户进一步明确：基础信号应具有明显的接收器选择性，例如食物源主要激活一个接收器，其他接收器可以没有响应；复杂来源可同时携带食物成分及额外成分，模型根据组合和后果学习其意义。这取代“每种来源都必须稠密激活多个通道”的候选，不取消多维感知。

接收器对应可感知成分，不等于输入来源身份、危险类别或避让答案；第四接收器也不应自动等于捕食者。用户以前三个接收器为基础信号举例，未最终固定全部物理场与接收器数量。死亡后继承如何形成学习信号另作决定，不能把代际学习与同一个体在线适应混为同一结果。
