# 哪些固定信号规则能让局部观察包含可学习的方向？

## Question

在用户选择的感知表示下，离巢标记、携食返程标记、有限范围食物源气味与危险场应如何产生、衰减和被采样？方向信息是否会被饱和、扩散或路径交叉抹平？哪些情形本就无法仅凭当前局部观察辨认正确方向？

输出有依据的可选信号规则与观察边界，区分本项目仿真设定和生物学事实。明确代码固定的释放行为，避免从巢穴真值生成方向输入。具体阈值需有依据或标为待校准，不用训练成功与否反向改写测试场景。

## Answer

已完成当前物理场和感知代码核对，以及混合可辨别性和路径梯度的有界分析，见[信号场调查](../../../docs/engineering/mixed-signal-field-options.md)。现实现仍有远距离首次食物方向、模型决定释放，不满足新要求；选择性基础通道本身不与用户最新要求冲突。

保留绝对强度与检查路径梯度仍适用；稠密混合候选已由用户最新的选择性感知要求替换。固定满秩混合的信息量与分通道表示相同，不可夸大为未知信号识别。起始配置另由对话条目选择，未做环境修改或训练。
