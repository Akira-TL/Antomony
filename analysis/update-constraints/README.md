## Question / Target Contrast

在既有四步写入前的同一局部观察上，更新是否因分布或参数约束、角度非线性饱和而几乎不改变实际动作？本轮只测量已发生写入，不评价新的参数、学习规则或未来收益。

## Inputs and Data Freeze

数据集 `window-cadence`，版本 `20260926T165559-3`。只重建四步配置19701、19702的固定接受及全部跳过四世界。结果前已从原始更新记录核对实际写入154次，与已发表项目记录一致；实际纳入量仍由全部记录和世界汇总交叉验证，不强凑数量。既有行为和生存结果已见，这是结果后的探索分析。

输入文件清单、执行元数据和四步协议的SHA-256值固定于本次配置；正式计算先核对完整4470文件及所有原始模型身份。禁止读取现场临时演示数据替代原批次。

## Unit of Inference

整巢种子19701、19702。个体、窗口、写入及生命相关，不将154次写入当独立重复，不作显著性、总体比例或等效性判断。

## Primary Analysis

先重建每次随机方向、冻结动作、隐藏状态及随机状态快照，核对实际参数链、伤害反馈和判断时序。仅实际写入逐次输出如下测量；全部跳过及零提案数量用于核对覆盖，不分析其未执行的替代世界。

方向概率总变差为16类概率差绝对值之和的一半，再在窗口状态间取均值。实际动作总变差先将相同前进布尔值和精确转向量合并；前进概率和转角期望差另报，不把方向角变化当运动改善。

记录实际写入前后平均及最大相对熵与其上限之比、已保存的回溯次数、实际参数增量范数及累计残差范数与各自上限之比。相对熵须与保存的诊断相符，容差0.000002；参数不可超过已有上限加0.00001。比例达到0.95仅作接近边界的描述，不能识别哪项约束单独造成失败，也不据此放宽限制。

按已有公式计算角度变化绝对值均值、修改前角度函数的归一化导数 `1-tanh(z)^2`；导数不大于0.01作为饱和描述。输出窗口陌生特征矩阵及动作概率对45参数的雅可比矩阵数值秩，使用NumPy默认奇异值容差，即最大奇异值乘最大矩阵维度和双精度机器精度。每状态仅一旋转角，因此雅可比矩阵秩上界为有效窗口状态数，不由此推断全任务表达能力不足。

逐种子报告所有写入的最小值、中位数、最大值、均值，以及接近边界、饱和、回溯、实际动作总变差小于0.01的次数。所有连续测量保留，不把描述阈值变成部署判据。没有新学习率、窗口、阈值或参数规模搜索。

## Exploratory / Sensitivity Analyses

复用此前已定义的实际前进与转向期望差，保留每次受伤窗口标记；不新增分组筛选、未来分支或敏感性搜索。

## Assumptions and Diagnostics

解析雅可比矩阵用独立中央差分检验；合并动作的总变差用人工可计算实例检验。合成短轨迹检查动作、参数、记忆重建与保存诊断篡改拒绝。实际模型、完整清单、协议或重建不符即停止解释，不跳过失败状态。单步实际动作分布不包含重新行走的碰撞或未来危险；不能由此推断生存因果效果。

## Result Boundary

本分析可排查变化是否主要消失在约束或动作映射中，不能确定最优学习目标、验证更大步长有效、证明45参数架构必然不足，也不能证明自训练相对MLP有优势。无论结果如何均保留四步设置、旧冻结设计及失败判据；不自动开启反事实动作试验或训练接受器。

当前结果不支持“既有更新普遍被参数上限或角度饱和卡住，实际动作几乎不变”这一笼统解释。分布约束确实限制了每次旋转，但动作分布变化仍实际存在；不能进一步推断当前幅度足以应对危险，也不能推断放宽约束会改善结果。方向角和一步转角期望存在明显数值差别，但平均转角含不同随机方向的抵消，不等于每次实际动作只转这么小。四步内低秩是接口结构的局部性质，不证明整个模型只有四个有效参数或无法学习。下一条有判别力证据应区分反馈方向与实际行动后果，本轮到此停止。
