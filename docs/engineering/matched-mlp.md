# 参数规模接近的普通多层感知机

## 结构与边界

现有自学习候选的总参数为1697：基础策略1365、记忆64、动作82、方向修正45、接受决策141。
普通多层感知机（Multilayer Perceptron, MLP）原总量1447，差异约17.3%，不能直接称为同规模。

普通MLP现支持第一隐藏层显式设为17，结构为86→17→8，方向输出2、价值输出1。
策略1650参数，加原动作82后共1732，比自学习候选多35，约2.06%。
新增隐藏单元均进入前向运算并收到方向损失的梯度，不使用无效占位参数。

这是总存储参数的近似匹配，不是计算量或有效可训练容量完全匹配：

- 17宽策略包含850个基础课程保持为零的预留接收器连接；原14宽有700个。
- 价值输出9参数在信号课程冻结，不参与行为方向，不能当成经过训练的回报估计。
- 动作模型82参数冻结；当前自学习候选的基础网络和64个零记忆连接也冻结。
- 基础课程方向可训练且有非零输入的参数，17宽为791，14宽为656。
- 自学习模块在部署时另有更新计算；普通MLP没有循环历史或在线更新。

因此必须同时报告基础能力、参数类别与计算成本。仅参数量接近不支持自学习优势。

## 兼容性与训练入口

`FeedforwardPolicy(seed, hidden_width=17)` 创建新模型；默认14不变。
`comparison.run.Config.hidden_width` 传入原信号课程，默认14，未改采样、损失或学习率。
17宽保存为 `local-mlp-v2`，显式保存宽度；14宽继续保存为 `local-mlp-v1`。
加载器兼容旧文件并拒绝非法宽度、维度不匹配和非有限权重。

当前 `local-mlp-memory-v1` 只支持原14宽底座，构造时明确拒绝17宽，
避免生成能够运行却无法恢复的记忆检查点。不会升级或覆盖既有训练产物。

45项针对性测试通过，包括14宽原始初始化逐值一致、17宽保存恢复逐值一致、
历史独立、新单元梯度、个体隔离以及两步训练逐次保存。
上述只是工程兼容性验证；随后完成的正式训练与资格结果见下节。
