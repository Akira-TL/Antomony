# 默认场景能否直接展示多食物源与墙体阻断信息素？

Type: task
Status: resolved
Parent: ../map.md

## Goal

在扩大后的实时对照场景中放置多个食物源和不会封死路径的墙体，使墙体阻断信息素的机制能够在默认演示中直接观察。

## Acceptance

- 默认至少有三个食物源，库存总量守恒。
- 默认墙体不覆盖巢穴、食物源或出生蚂蚁，也不封死全部路径。
- 墙体同时阻断局部信号传播与信息素网格扩散。
- 三组获得完全相同的初始食物和墙体布局。

## Answer

实时场景现在将初始总库存确定性拆分到三个食物源，并在每个来源的朝巢一侧放置一段可绕行短墙。墙体初始化后立即写入信息素阻挡掩码；三组的来源、库存、墙体和阻挡网格完全一致，来源信号不能穿过墙体。
