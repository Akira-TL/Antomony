# 群体往返与返巢预算

用户于2026-09-26授权后续课程使用多只蚂蚁，并选择“探索预算归零，仍保留返巢体力”。本接口只定义仿真与学习输入，不表示模型已经学会返巢。

## 环境约定

首轮工程候选为8只蚂蚁、16份食物、512个同步物理步。每只拥有160步探索预算及160步返巢体力。停留、转向和前进都消耗时间预算；探索预算先消耗，之后才消耗返巢体力。探索预算归零后允许原来的全部行动，程序不修改模型方向。返巢体力归零终止该个体，同一步确实回巢则先补给。

只有实际离开巢区再进入巢穴才补给并重置轨迹释放起点。离开判据为距巢大于0.9，进入为小于0.65，避免边界抖动。一直待在巢内不重复补给或得分。耗尽个体退出本回合，暂不实现尸体障碍、复活或死亡继承。

观察为9个位置的8维接收器响应、原四项自身状态，以及两个归一化剩余预算。没有全局巢方向、隐藏食物坐标、目标距离或“正确方向”输入。食物源仅通过局部有限范围气味被感知。

## 奖励与共享边界

- 原无线索空载低浓度奖励保留，但探索预算归零后停止。没有额外位移或访问次数门槛。
- 实际拾取加1、实际交付加4。空载且探索预算耗尽后实际回巢补给加2，不与同次交付叠加。返巢体力耗尽扣2。
- 上述数值是首次开发试验参数，不是已证明合理的奖励设计。停在巢外等预算耗尽再短距离返巢仍可能形成投机行为，验收必须结合轨迹及搬运量，不能仅看总奖励。
- 蚂蚁共享库存、物理场、固定释放的信息素；信息素每物理步仅蒸发扩散一次。先计算全部位移与场采样，再集中释放，避免逐只处理造成蒸发倍增或探索奖励顺序偏差。
- 同时接触最后一份食物按随时间轮转的编号优先级分配，不可重复拾取。同组使用圆形个体碰撞；不同条件各自创建世界，绝不共享场或库存。
- 模型参数、隐藏历史、优化器与采样随机数必须各自独立。共同初始检查点不等于运行中共享可变权重。

旧单蚁环境与76维观察保持兼容。新环境是后续训练入口，不覆盖旧8771数据或现有演示。

## 模型接口

`local-foraging-v4` 在原76维观察后增加探索预算比例和返巢体力比例，同时将信号调制输入从是否携食一项扩为三项。`with_budgets()` 显式复制旧模型，并将新增32个权重置零；迁移本身不改变旧模型输出。第4至8接收器的80个连接仍冻结且为零。动作模型没有增加任何输入，仍只接收单位方向。

基础监督课程先教授空载预算耗尽时沿局部离巢浓度梯度行进，标签仅在训练中使用。未耗尽样本的预算取0.25至1；低于0.25但未归零的过渡区不人为指定固定返航阈值，必须在实际轨迹中检查。该监督先验不等于学会最优返航时机，更不等于已学会控制自修改。后续奖励课程才能检验真实经历下的取舍。
