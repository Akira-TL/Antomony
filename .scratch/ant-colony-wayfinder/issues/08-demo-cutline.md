# 首版保留哪些干预、验收与离线降级才能形成完整路演？

Type: grilling
Status: ready-for-human
Mode: HITL
Parent: ../map.md
Blocked by: 03, 06, 07

## Question

结合粗原型及验证设计，与用户锁定两天内的首版演示边界，而不是根据早期口头提议全量实现。

决定第一条必须成功解释的干预路径、次要交互、最低个体规模和性能门槛、是否并排对照、哪些个体状态要暴露，以及怎样处理未达标的回退功能。障碍、假信息素、目标迁移、窄门拥堵不是默认全部必做。

现场按钮只能改变环境，不能给算法发送正确方向、变化标签、预定回退时刻或隐含奖励。真实运行、实验回放和录屏降级必须可区分。赛前已有代码与比赛新增工作分别披露，比赛准入规则未核验则保留独立阻塞，不擅自对外发布。

解决后形成可交给实现流程的范围与验收摘要；正式产品代码、依赖安装、完整 UI 和训练由下一工作项负责，不塞进本决策地图。
