# 辅助奖励的势函数方法与应用边界

## 本轮问题

能否用辅助反馈帮助学习，但不再把停留或空载循环变成独立赚钱目标？本轮只核验固定势函数的回报关系，不声称覆盖全部奖励塑形方法，也不修改当前训练目标。

基础证据是[Ng等，1999](<../../literature/papers/Policy invariance under reward transformations: Theory and application to reward shaping - Ng - 1999.md>)和[Grzes，2017](<../../literature/papers/Reward Shaping in Episodic Reinforcement Learning - Grzes - 2017.md>)。已完整阅读、核对图表，并从2017参考文献[22]回查原定理；定向边界检索没有改变以下判断。当前[工程边界测试](../engineering/reward-objective-boundaries.md)是本项目实现证据，不与文献中的实验混用。

## 已有依据

基于势函数的奖励塑形（Potential-Based Reward Shaping, PBRS）增加：

`F_t = gamma * Phi_{t+1} - Phi_t`

对长度N的完整轨迹，折扣辅助回报严格等于：

`sum(gamma^t * F_t) = gamma^N * Phi_N - Phi_0`

同一起点且终止势为零时，辅助总回报只是固定的 `-Phi_0`，不能改变同一原任务下的策略排序。这里是终止**势**为零，不是最后一个辅助奖励为零。折扣必须与任务回报一致；不能把折扣情况下的闭合循环笼统说成“每圈辅助分都是零”。

## 对本项目的推论

以下是基于公式与现有代码的项目判断，不是两篇论文的蚁群实验结论。

1. **先确定原任务。** 若原任务就偏好零搬运，保持其策略排序只会保留问题。搬运与死亡取舍仍需用户决定；势函数不替代这个选择。
2. **不能把16步处理点当整场结束。** 当前 `observed-window` 在边界使用零后续价值，不等同于已处理完任务。保留末势会留下动作相关残项；每窗强行归零虽然能保该短窗的回报排序，却不因此恢复长期任务。若声称恢复长期目标，必须另有后续价值或合法延迟反馈机制。
3. **复活要完整记账。** 当前目标在复活后继续累计搬运，死亡及重生转移不能凭空丢掉原势再免费获得新势。若改成每条生命独立回合，则估计目标已经改变，需要明确登记。
4. **不能偷加全局导航答案。** 势若依赖隐藏食物或巢穴距离，即使不直接拼进策略输入，奖励也传入了额外任务信息。用户只允许局部信号，这条边界同样约束塑形。
5. **局部感知和共享场不等于定理条件已全部成立。** 相消代数可逐轨迹检查，但多蚁学习的稳定性、收敛、有限样本优势仍需实测。信息素上升也不自动表示任务进展。
6. **保持负项。** 将负塑形裁到零、只保留进展奖励或任意重置势，都会破坏上述相消关系，必须重新检查，不能沿用保证。

本轮不指定实际势函数、不选择奖惩系数、不扩大训练。下一步应先完成可独立核对的算术边界检查；之后在用户确认任务取舍的前提下，固定奖励、终止定义和评价时间范围，再进行有限对照。数学恒等式、软件测试通过和真实自训练有效是三种不同证据。
