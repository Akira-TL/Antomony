# 独立神经蚁群：首版使用与验收

## 打开现场

本机地址：`http://localhost:8765`。Three.js 页面与 Python 模拟器由同一个本地服务提供，不依赖云端推理。多个页面连接的是同一个现场；一个页面的暂停或重置会影响其他页面。

```bash
cd /home/Akira/Projects/MathHackson
bash scripts/colony/start.sh
bash scripts/colony/stop.sh
```

启动脚本只使用本项目 PID；端口被其他程序占用时拒绝覆盖。服务绑定 `127.0.0.1`，不修改网卡、路由、代理、防火墙或 nginx。首次在新的 checkout 运行前使用 `uv sync --locked`；没有前端构建时，启动脚本执行 `npm --prefix web ci` 与构建。已有前端修改后手工执行 `npm --prefix web run build`，再重启服务。

## 如何操作

默认 32 只个体。观察模式下拖动旋转、滚轮缩放，点击个体或右侧下拉框查看其模型。切换到拆墙、资源或信息素工具后，点击地面执行对应操作。放墙先随鼠标显示真实尺寸预览；右侧调整墙长，按R或按钮旋转，点击放置。经过的个体会就近让位，巢穴、资源和已有墙体仍不能覆盖。观察模式以外关闭镜头拖动，避免编辑和相机手势混淆。

暂停后单步只推进一个仿真步。倍速选择的是目标推进速度，实际速度仍受 CPU 限制；页面帧率、仿真时间和仿真单步耗时分别显示，不把渲染帧率当作学习或推理速度。

中央横向外力只改变世界物理；模型不知道滑杆的数值和干预类别。清空信息素不修改模型参数。冻结全部或单个个体后，感知与行动继续，但对应参数指纹和更新次数应停止变化；恢复学习后才重新更新。重新开始会重新独立初始化和预热各个体，不复制一个共同训练模板。

导出按钮保存当前真实快照，不是可恢复完整训练状态的模型检查点。

## 模型到底做了什么

每只个体具有独立的 `8 → 24 → 16 → 3` 多层感知机、独立随机数和参数更新历史。两层隐藏参数在各自生成的局部运动练习中预热；现场只在线调整 51 个输出层参数。预热标签是局部净空条件下的运动/接触后果，不是全局路径或搬运策略的正确答案。

个体预测十二个候选方向的身体位移与接触，再用预测值、局部信息素意向、近距离可见资源、自身运动积分回巢与探索偏好打分选动作。因此神经预测参与方向选择，但首版不是从零训练出了端到端强化学习策略。

实际执行之后，个体仅使用自己的真实位移和接触反馈更新；误差显示的是更新前预测与执行后反馈的差异。共享的是环境中的信息素，不是神经权重、梯度或经验池。神经小图显示部分实际激活；连线是结构示意，不是假装测得的突触权重或学习归因。

信息素沉积/蒸发、拾取/放下、探索偏好属于明确的人工先验。圆形碰撞的分离由物理层负责。看见绕墙、没有穿墙或路径改变，并不自动证明神经网络学会了避障。当前回退功能未启用，不生成回退事件，也不宣称其增益。

## 验证入口

```bash
# 模块与场景测试
bash scripts/colony/check.sh

# 必须先启动服务；会暂停、编辑、冻结、重置现场，勿在正式演讲中运行
bash scripts/colony/smoke.sh

# 全部已有 Python 测试与前端类型/构建检查
uv run pytest -q
npm --prefix web run build
```

已完成本机真实 HTTP/WebSocket 验收：暂停单步、全部冻结、单只恢复且其他参数不变、拒绝覆盖巢穴的墙、真实新增/删除墙体、信息素干预不直接改模型、重新预热并恢复现场。浏览器实际打开页面，完成真实按钮点击、参数冻结检查，并检查了渲染截图。日志在 `logs/colony-smoke.json`、`logs/colony-server.log`；截图为本机 `logs/colony-final.jpg`。

实际连续运行已观察到发现资源、拾取、搬回及累计更新，不是预录运输动画。这项运行检查没有固定科研比较条件，不能转换为运输率改善或普遍学习优势的证据。独立预热的局部预测误差下降通过工程测试，不等于全群寻路能力已验证。

## 开发试跑结果

执行前提交了固定配置脚本 `scripts/colony/benchmark.py`（提交 `0174248`）。种子101、102、103；每组12个体、400个仿真步；第100步开始改变中央区域横向外力。每个条件使用独立世界和信息素，各组只改变是否在线更新。完整输出见 [开发试跑记录](ant-colony-validation.json)，复现入口为 `bash scripts/colony/benchmark.sh`。

| 世界种子 | 冻结 / 在线：搬回块数 | 冻结 / 在线：更新前预测均方误差 | 冻结 / 在线：每100次行动接触数 |
| --- | ---: | ---: | ---: |
| 101 | 7 / 8 | 0.13991 / 0.03749 | 15.94 / 8.58 |
| 102 | 6 / 7 | 0.13323 / 0.03675 | 15.77 / 7.46 |
| 103 | 10 / 8 | 0.10540 / 0.02938 | 9.15 / 5.73 |

三个世界中在线条件的实际轨迹预测误差与接触率均较低，但两组总搬运量同为23，因此当前不能声称运输效率提高。预测误差来自各自实际执行的轨迹，不是固定同一轨迹上的离线精度比较。这是3组开发可行性试跑，不是充分重复的确认性研究，不外推到所有种子、复杂迷宫或硬件。
