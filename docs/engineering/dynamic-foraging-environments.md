# 动态局部来源的工程契约

## 当前范围

在既有 `DisturbedColony` 中加入有限减速、周期性作用和预定路线移动。默认值保持旧静态来源：不减速、不移动，非作用时段仍保留原有气味。历史配置与模型文件不改写。

这只是后续对照的环境能力，不是新的研究结果。当前接受模型在基础留出上仍失败，规则与神经模型的完整基础能力也尚未匹配。不能以工程测试通过宣称自训练有效。

## 物理与观察

- `speed_multiplier` 只缩放来源附近的主动平移，不缩放转向，不替模型选方向；是否处在 `slowdown_radius` 内按行动开始位置判断。碰撞分离仍属于原物理层。预算按时间步消耗，不因减速而减免。
- `active_from` 包含起始步，`active_until` 不包含结束步。可选 `period_steps` 与 `active_steps` 必须成对设置，周期相位以起始步为零点。伤害与减速使用同一行动步的作用状态。
- `inactive_signal_scale` 决定非作用时段的气味强度比例；默认1保持原有持续来源。设为0时气味与周期作用同步关闭。不能把配置中的状态标志直接输入模型。
- `motion_amplitude` 指来源沿巢穴至食物连线的垂直方向做正弦往返的幅度；`motion_period_steps` 指周期。位置只取决于初始布局、配置和仿真步数，不追踪个体。越界路线拒绝创建。
- 每一步先使用当前来源完成动作与伤害判断，再推进来源供下一次感知。采用离散时间接触，不额外模拟来源两位置之间的连续扫掠伤害。
- 来源继续通过九个局部采样位置的八接收器叠加响应，不新增全局坐标、类别、周期相位或正确方向。巢穴源仍只有有限作用范围。

## 配对与限制

相同世界种子、配置和步数产生相同外部日程；不依赖各组消耗随机数的次数。各组信息素场、库存和个体仍独立。某组提前终止后，不把终止后的缺测轨迹当作持续存活。

这里的移动来源可模拟沿固定路线巡游的危险，不代表已实现根据猎物行为追逐的捕食者。后者会涉及“同步外部规则”与“实际位置相同”的不同对照要求，不能混称已经完成。
