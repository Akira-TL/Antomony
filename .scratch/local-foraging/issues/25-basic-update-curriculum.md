# 无危险基础更新课程的采样支持

给已有分支采样器增加显式初始残差扰动，默认0保留旧行为。扰动只发生在新个体第一次行动前，使用个体独立随机流、不修改源模型、不计作学习写入；非零初始残差须保存第0步快照，主轨迹后续仍全部跳过。允许在不引入死亡、减速、周期机制的基础往返场景中收集修正和误改的后果。

本条不运行完整研究采样。后续设计需固定种子、幅度、线索和完整训练/留出规则；人工参数扰动的有效性不能替代未见环境迁移。

验收：3项新增测试及10项既有候选/分支测试通过。初始扰动可重建，不消耗行动随机流，基础权重不变，保存恢复一致；安全界限、旧协议默认0、重复初始化均有覆盖。采样结束检查相对初始残差逐值不变，不再错误地把非零初始化当成分支污染。
