## Primary Analysis

对每个评价回合，计算实际奖励第5至96帧平均值及第73至96帧平均值。奖励为已选择单位方向与当帧隐藏目标方向的点积，不减写入成本。按条件、种子、回合编号配对学得组与三参照；先求回合差，再对64回合等权平均。每条件和每组的原始回合值、均值与全部配对差保留，不仅保存布尔结论。

每个初始化分别满足全部条件才为通过：持续关联相对全部跳过的两窗口差均至少0.03；原方向参照相对全部跳过的两窗口差均至少-0.02；持续关联和短暂变化两条件等权平均的第5至96帧奖励，分别相对全部接受、等次数随机接受都至少高0.005。最后两条件合并的判断机会中，学得组接受和跳过各至少10%，且至少一次实际写入范数大于1e-9。两初始化均通过才继续考虑真实局部场迁移。

每回合24次判断；每初始化两条件共128回合、3072次机会。比例按这个合并分母计算，不对每条件另设门槛。末帧判断虽不能影响后续行动，仍按既定实现计入机会；不能在见结果后排除末帧来改变比例。

## Result Boundary

仅检验两个初始化的合成方向反馈基础可行性。四组均使用训练后的调制结构，即使通过也只说明该结构的在线写入和接受时机有课程内作用，不能把作用归因于外层训练；随机初始调制器也可能有效，须在过门槛后另行比较相同初始化但未经外层训练的结构。本次不追加第五组。

没有物理运动、食物运输或危险，因此不能声称真实蚁群生存或未见复杂环境优势。关闭写入和同结构消融不替代用户要求的普通MLP及规则组；二元接受时机是否在这个小课程有效，也不等于新颖性或普遍可学习性已经证明。选路由旧结果启发，当前判据先于新课程结果固定，不冒充外部预注册。

本配置未表现出学会接受与跳过时机的证据，两个初始化均未达到预定门槛。停止延长该配置，不接入8775；这一结果不否定所有自训练方法，也不从这些配对差推断未检验的失败机制。
