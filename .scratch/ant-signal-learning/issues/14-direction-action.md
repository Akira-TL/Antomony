# 只给方向的动作模型如何训练，停走表示什么？

## Question

用户已要求基础动作模型重训。建议输入只保留身体坐标下期望方向的正弦、余弦，输出前进布尔值与连续转向量；训练时用朝向误差和沿指令方向的实际位移评价动作，奖励只用于优化，不作为下一步动作输入，也不经隐藏状态引入距离相关反馈。

没有距离或停止命令时，动作模型无法区分同一方向上的“已经到达”和“尚未到达”。是否先把停走定义为执行转向时的动作选择，而不训练到点停车；拾取、交付后由方向层更换期望方向，环境执行交互事件？建议如此；不要暗中补回目标距离。具体网络结构、随机方向覆盖与转向上限在课程中确定。
