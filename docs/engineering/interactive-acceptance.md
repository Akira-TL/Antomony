## 启停与操作

首次检出先在仓库根目录安装锁定依赖和构建；所需最小模型已包含于 `models/interactive/`，不需要下载本机训练日志：

```bash
uv sync --locked
npm --prefix web ci
npm --prefix web run build
bash scripts/interactive/start.sh
# 支持用户级systemd的本机也可使用 start.sh --managed
bash scripts/interactive/stop.sh
```

端口占用时拒绝覆盖，可通过 `PORT` 改用其他端口。服务只绑定 `127.0.0.1`，日志为 `logs/interactive-8775.log`。多个标签共同操作同一现场；重新开始会保留旧运行目录，但新一轮重新加载基础参数，不继承上一轮的在线修正。

页面左上为固定接受的自训练模型，右上为普通MLP，左下为纯代码规则，右下为控制和参数。顶部提供同步暂停、单步、目标倍速、全景、保存、导出和新一轮。实际速度受CPU限制，右下角报告三组真实推进耗时，不把显示倍速当成已达到的速度。服务端每步只生成并发布一次完整帧，行动后观察同时供反馈和展示使用；展示帧经同源WebSocket长连接主动推送，页面按实际帧间隔插值，同一时点不重复上传信息素纹理。编辑和控制命令仍使用可靠HTTP请求。

选择墙体、食物或作用区后，在任一场景移动鼠标显示三组共同落点预览；绿色才表示当前允许，点击时服务器仍重新核验。墙体工具下滚动鼠标滚轮会以15度步长旋转当前预览。墙体覆盖蚂蚁时，三组分别把被覆盖个体就近移到墙体两侧，只改变位置并保留其模型、记忆和其他状态；任一组没有安全空位则整次拒绝。移除工具只删除墙或作用区；Escape取消编辑。回看状态不允许场景写入，返回现场后再编辑。

“参数与个体”可选组、个体和模块，每页9条真实参数折线，悬停显示步数与数值；方向修正按接收点和R4至R8标注，冻结模块单独显示。跟随按钮放大所选个体，全景按钮恢复。近期记忆读取前1、2、3、4步，稀疏记忆读取前4、8、12、16步，但当前记忆权重仍为零且冻结，不能称为已学会使用记忆。

## 多食物源

`interactive.world.EditableColony` 复用当前局部信号训练环境，不使用早期导航器。每个来源有独立位置与库存；耗尽后不再发出食物源信号，已有携食轨迹仍按场规则衰减。拾取使用真实局部接触，位置与来源编号不进入神经观察。

来源总库存、个体携带及累计交付守恒。死亡或体力耗尽时，携带食物退回原来源，不增加交付，不奖励复活。添加资源保留当前个体与步数；运行达到设定总步数才终止，不能因库存暂时耗尽阻止后续添加。

每个世界分别持有来源、库存及双信息素场。编辑只改变环境，不修改网络、记忆或随机流。实时世界没有自动结束步数；新一轮只由人工触发。当前最多64个资源，每处1至4096份，拒绝非有限位置、出界、巢内、墙内与重叠位置；预览和提交都核验三组共同许可。青色表示离巢轨迹，橙色表示携食返程轨迹。
