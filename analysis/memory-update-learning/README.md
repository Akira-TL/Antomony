## Question / Target Contrast

四个留出整巢种子中，学习接受决策相对全部跳过及全部接受，在同一候选状态后最多64步的平均焦点奖励差，附焦点与整巢实际交付差。

## Inputs and Data Freeze

输入批次 `20260926T113733-2`，301条记录，训练196条、留出105条；2738文件及1344组模型快照。数据及清单固定于 `83faa7b`。首次拟合及留出计算前登记本分析；不读取其他课程、危险诊断或其他分析的输出。

## Unit of Inference

8个训练、4个留出整巢种子，每种子两种初始化条件。同巢个体、候选及两个条件相关，不把105条留出记录当105个独立世界。四个留出种子仅支持开发描述，不报告总体显著性或普遍改善保证。

## Primary Analysis

先校验全文件散列、协议与模型身份、世界分区、父轨迹帧、每份基础及记忆参数冻结、残差不变和快照配置。拟合前只取训练记录，检查候选约束、分支时限和无危险后果。八个接受模型各只用本个体记录训练200步，每25步及第0步保存；学习率、衰减及裁剪完全沿用冻结设计，不按训练损失挑轮次。

所有模型拟合完成后才解析留出标签。预测奖励差严格大于0才接受；每世界以全部入选候选为分母计算所选及全部接受奖励差，全部跳过为0，另报焦点与整巢交付差、预测均方误差、正负及相同标签数、接受数量。数值容差1e-6只用于标签计数，不改变接受阈值。

每个种子的两条件等权平均，再对四种子等权平均，不按候选数量加权。空世界标缺失，不填0。依冻结设计，至少3个完整种子优于全跳过与全接受，总体等权均值也同时优于两者，并至少一个留出世界有正的所选焦点交付差，才达到开发继续条件。任一条件缺失使总体判定不能通过。

## Exploratory / Sensitivity Analyses

只描述各个体样本数、标签覆盖与训练损失。不重选阈值、参数、个体或检查点，不追加种子。不存在结果前约定的其他敏感性计算。

## Assumptions and Diagnostics

候选基于已发生窗口奖励而非可靠长期价值，仍有截断与方差问题。分支只演化最多64步，父轨迹全部跳过，离线选择不等于连续在线策略。初始同向扰动是训练课程，未代表复杂环境。记忆参数为零且冻结，不据此声称学会使用记忆。个体参数1697，比现有普通MLP的1447多约17.3%，严格参数匹配仍未完成。

实现测试另用合成数值和临时短轨迹检查等权汇总、负均值、缺失条件、零阈值，以及篡改帧数、记忆参数和反馈配置会被拒绝；不把这些测试用于学习效果判断。

## Result Boundary

结果仅说明当前无危险课程与接受模型没有通过预定开发条件，不能据此否定所有自主学习结构。没有建立陌生减速、周期、危险组合的适应性，也没有完成跨模型比较。后续若评价此候选，必须保留其基础接受学习失败的身份，不称为已验证有效模型，不以更好的局部数字替代完整目标。
