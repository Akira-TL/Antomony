## Question / Target Contrast

同情境的另一次独立试行回报基线，是否比历史回报基线更有效地训练修改量和接受时机？当前为探索性方案，来源是前一配置的失败，不冒充原先预测或已识别的失败原因。

## Unit of Inference

两个外层初始化1721/1722是独立单位。两基线、训练前后、同情境独立试行、条件、回合和四种更新方式均有配对或嵌套依赖，不把轨迹数当独立模型数，不作总体显著性声明。

## Primary Analysis

科学规则以冻结设计的估计目标、分析对应及判别边界为唯一来源。分别计算每初始化、三条件第5至96帧和第73至96帧的配对方向奖励差，先逐回合差再等权平均；两关联条件联合差等权。

保留候选减历史基线、候选训练后减训练前，以及各组学得接受减全部跳过、全部接受和等次数随机接受。执行设计中全部三组继续条件，两个初始化都达标才通过；不降门槛、不换窗口、不挑保存点、不删负差值。方向奖励不等于实际搬运或生存。

## Exploratory / Sensitivity Analyses

只描述参数变化、接受比例和奖励时序，不追加搜索或仅凭结果宣称梯度方差机制。其他问题另行登记。

## Assumptions and Diagnostics

先核验完整清单、协议只改变基线方式、固定基础来源、所有保存点、初始参数逐值相同，以及关闭写入的行动跨基线和时点逐值相同。核验训练轮次完整、已保存的训练片段使用同一情境的成对轨迹；原始输入和目标逐值相同，派生基础方向允许1e-6的单精度舍入容差。这项容差在合成数据上发现并于正式执行前固定，不是结果后更换规则。

逐帧检查四步更新、跳过不变、单次及累计范数、实际方向奖励、等次数消融及摘要一致性；保留通道输入仍须为零。来源、形状、有限值、配对或判据失败时保留失败，不覆盖原件。
