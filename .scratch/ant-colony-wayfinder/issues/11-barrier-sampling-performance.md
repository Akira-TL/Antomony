# 64 只场景的信息素遮挡采样能否保持流畅？

Type: task
Status: resolved
Parent: ../map.md
Blocked by: 09, 10

## Goal

在不改变墙体遮挡判定和模型输入的前提下，跳过与局部接收器完全无关的远处来源与墙体，降低 64 × 3 实时世界的单步耗时。

## Acceptance

- 墙体附近的来源遮挡、天线跨墙遮挡和信息素沉积遮挡测试保持通过。
- 无信号响应的来源不执行几何遮挡计算。
- 与当前接收器线段包围范围不相交的墙体不执行线段矩形求交。
- 64 × 3 实际服务单步耗时较优化前的约 445 ms 明显下降。

## Answer

局部采样现在先计算来源响应；响应全为零时不再进行墙体求交。线段与所有接收点的包围范围若完全不碰墙体，也直接跳过精确求交。两项均为等价短路，不改变有响应、可能相交时的原判定。
