# 混合感知与固定信号场的设计依据

## 范围

用户已选择多维响应，并进一步明确基础信号可主要激活对应接收器，复杂来源通过响应组合供模型学习。本文检查现有代码与可辨别条件，提出待确认的仿真规则；不声称这些设置已经实现或通过训练验证，也不把仿真设定描述为蚂蚁生物学事实。

## 现有实现与新要求的差异

[信息素实现](../../src/mathhackson/colony/pheromone.py)只有两个物理场，采用相邻格扩散、指数蒸发和 0 至 8 的数值截断。半衰期分别为 45 与 35 个仿真时间单位。采样为格点取值，不是连续空间插值。

[往返环境](../../src/mathhackson/training/roundtrip_environment.py)仍接收模型的两个释放布尔输出；沉积间距按实际位移累计，但释放强度按经过步数衰减。原地转向虽然没有新增行进距离，仍会降低下一次释放强度。它还在首次交付前直接提供食物方向，尚未实现有限范围食物源气味或危险场。这些是将来需要替换的接口事实，不是本轮运行故障复现。

当前感知分别读取两个带语义通道，并在每个方向上取多个距离的最大浓度，再求方向差。这种预处理已包含方向摘要，尚未覆盖复杂来源的组合响应；但基础成分对应选择性接收器本身符合用户最新要求，不再以“通道容易辨认”作为否定理由。[当前局部感知](../../src/mathhackson/training/roundtrip_environment.py)

## 混合感知的可辨别条件

下面是候选感知模型的数学分析，不是已观察结果。令一个采样位置的四类物理浓度组成向量 `c`，接收器得到 `y = M c`。矩阵列表示各类来源对接收器的响应特征，模型只读 `y`，不读 `c`、类别编号、源实例编号或 `M`。

- 若四种浓度可任意同时变化，少于四个独立线性响应一般无法从单次观察唯一恢复全部浓度：矩阵列秩不足，存在不同混合产生相同响应。时空历史或稀疏来源先验可能缩小歧义，但不能默认网络必然补足。
- 若采用固定、满列秩且数值条件良好的四维响应，混合与分通道输入保留相同的信息量，只改变表示。用户关于“本质仍是信号源”的判断与此相容；不能把学会固定混合矩阵称为学会识别任意未知信号。
- 不宜在每个位置各自归一化到单位长度，否则丢失绝对强度，而低浓度探索正需要这一信息。可使用固定尺度或保留绝对强度的有界压缩；饱和区应当被明确识别。
- 不同源的特征不应在每回合无条件随机交换而不提供任何适应证据；这会把同一响应对应的任务意义任意改写。

原候选要求四个稠密且非独热的固定响应通道，现已撤下。按用户最新要求，基础成分可以产生近似单通道的明显响应，复杂来源同时释放多个成分；来源身份与成分不同，携带食物成分的对象不必安全。接收器不应直接输出“捕食者”标签，也不应由代码规定某通道出现便转向逃跑。

采样位置数与响应维度是两个不同量；新增同类食物源不增加输入宽度。接收器数量与基础成分清单仍待确认。若测试复杂组合，后续应加入含相同额外成分但无害的来源等可区分条件，防止“第四通道高就逃跑”的简单规则冒充组合学习；这是待设计的对照，不是已经验证的结论。

## 固定信号规则的候选起点

| 物理成分 | 环境生成方式 | 需要防止的歧义 |
| --- | --- | --- |
| 离巢标记 | 空载行进按实际路程定距沉积，离开巢穴后强度随路程衰减 | 等待或转向不能被当成前进路程；多次重复沉积可能掩盖路径方向 |
| 食物轨迹 | 实际拾取后携食返程定距沉积，强度随离开拾取位置后的路程衰减 | 不在空载探索途中自动制造食物轨迹 |
| 食物源气味 | 每个食物源产生有限范围、随距离衰减的标量场，范围外为零 | 行动输入不附带源坐标或真实食物方向 |
| 危险场 | 由危险源产生独立的局部场，按其位置和强度变化 | 有危险信号不等于已经实现捕食、受伤或存活任务 |

物理场由环境保存类别，用于生成混合响应和计算训练奖励；环境知道类别不等于网络得到标签。释放规则由代码执行，所有对照共享同样物理规则；奖励不能绕过方向层直接驱动行动。

第一阶段可考虑平滑且有限支持的食物气味，例如范围内 `A * (1 - d / R)^2`，范围外为零；这是可调整的仿真函数而非生物学定律。范围、强度和噪声需在课程中固定并留出变化条件，不用整个场景都能闻到食物来冒充探索。

## 路径方向不能仅凭“有浓度”保证

浓度较高不一定代表更接近巢穴。以匀速直线路径为简化分析：沿路程的沉积为 `exp(-s / L)`，蒸发为 `exp(-lambda * age)`，速度为 `v`，在同一观察时刻的沿路梯度符号由 `-1 / L + lambda / v` 决定。过快蒸发或过慢移动可以改变强弱顺序。这一推导只用于约束参数候选，实际扩散、弯曲和交叉路径更复杂。

因此第一阶段需要在预期往返时长内保持可感知痕迹，并覆盖停走、折返与路径交叉。两个局部场产生同样响应但指向不同目的地时，必须允许记忆或探索，不能强制用隐藏巢穴方位作为唯一即时标签。
