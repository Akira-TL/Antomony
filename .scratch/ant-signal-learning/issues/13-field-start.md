# 第一阶段采用怎样的混合感知与固定信号规则？

## Question

依据[信号场调查](../../../docs/engineering/mixed-signal-field-options.md)，基础信号使用选择性接收器、复杂来源产生组合响应后，如何固定成分清单、采样位置和信息素释放规则？用户举例的三个基础接收器尚不等于已经删去两类轨迹与食物源气味中的任何一种物理来源。

需明确首版危险场是否只留感知接口或同时进入课程，以及未知环境首先改变源的组合、强度和动态还是响应特征本身。固定可逆混合保留分通道方案的信息量，不可将其当作通用未知类别识别已经得到验证。

## Comments

用户在上一轮三项推荐后回复“继续”，按项目约定确认：空载探索期间按仿真时间持续释放离巢标记，原地转向或停留也释放；不再沿用只按移动距离沉积的候选。浓度奖励本身不增加位移或访问次数条件。

本条尚未完整解决：待确认基础成分与接收器配置、危险信号进入课程的阶段，以及低浓度奖励是否只适用于无食物线索的空载探索。释放强度与衰减、扩散蒸发、奖励采样顺序仍需课程中的工程校准；不能将“持续释放”当作已经证明防止停留获利或能够归巢。

下一轮建议：先用食物源气味、离巢轨迹、携食返程轨迹三类基础成分，另留一个非危险标签的响应通道；食物气味与携食返程轨迹不合并。危险交互放在基础往返通过后的一般学习课程，并为最终测试留出新组合与新动态。低浓度探索奖励只用于空载且没有可检测食物线索的阶段，携食回程不鼓励离开路径。上述三项尚待用户选择。
