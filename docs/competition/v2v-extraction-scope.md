# V2V 单一机制提取范围

## 当前决定与来源

用户本轮要求：从 V2V 提取能够稳定验证、具有重要意义的一小部分，在两天开发窗口内快速形成可验证作品；不搬出完整架构和大量尚未验证的猜想。

助手建议以“小型神经网络的可逆在线更新”为一个候选研究切片。当前先提取有确定语义和独立测试的参数执行层，不把学习控制器、巩固控制器、动作信用或完整认知架构一并当作成熟实现。该范围是助手的可撤销实施选择，不等同于用户已正式报定赛道或认可科研有效性。

## 为什么选择这一块

V2V 的 `src/v2v/runtime/fast_residual.py` 只依赖 NumPy 和 Python 标准库，已有独立测试，不需要 Unity、GPU、长期记忆数据库、25-Block 架构或原项目检查点。它明确实现：稳定参数加临时增量、有限的近期修改记录、指定修改的部分/全部回退、保持有效参数的巩固，以及“先处理旧修改，最后加入新修改”的顺序。

这是可立即隔离验证的执行机制，不是已经证明的自主学习策略。后续唯一新增科学问题是：在没有变化类型答案的连续预测任务中，依据当时真正可获得的后续局部反馈进行回退，是否比相同预算下不回退或整体恢复更有用。

原始 V2V 的研究首页和结论继承图仍将 fast-first 与学习控制保留为机制级支持。其 `run_predictor_learning_gate_credit_probe.py` 同时明确使用两个独立预测器、两个输入情境，并通过 `context_index` 选择当前输入位置；因此原实验不能证明对未标记的临时扰动与永久变化的通用自主辨别。`run_unified_history_conditioned_consolidation_probe.py` 还先训练历史预测器与巩固控制器。本项目不静默搬入这些前置训练和条件身份。

## 必须守住的数学边界

设有效参数为 `S + F`，近期记录是已经计入 `F` 的增量身份，而不是额外加到前向里的参数。巩固比例 c 执行 `S' = S + cF`、`F' = (1-c)F`；在实数算术下有效参数相同，浮点实现只在明确容差内验收。

回退某个仍保留身份的增量，是减去它尚未巩固的部分。它不是删除一条训练样本后重新训练的等价操作；后续更新已依赖旧更新时，单次相减不能抹去间接影响。近期记录过期后，不承诺精确撤销那条修改。全部巩固后，该部分也不再具有原有的近期回退身份。

若有 P 个可适应参数、保留 K 条完整增量，额外存储量为 O(PK)，不能宣传为常数开销。因此候选作品只适应一个小型预测头或小规模网络，不复制大型模型全部参数历史。

回退功能本身不保证预测更好；谁来触发回退必须明确披露。人工按钮或已知变化标签只能做工程演示/阳性对照，不能作为自主策略结果。

## 最短作品路径

目标受众为神经网络赛道评委。最终要验证的时刻是：短暂污染结束后，系统能否较快恢复，同时在真正长期变化时仍然适应。

候选端到端路径：连续输入 → 小型神经预测器提前输出 → 后续观察到来 → 局部误差及更新影响估计 → 保留或撤回有限的近期更新 → 下一次预测。网络结构、输入流和预算在比较组之间相同。

当前优先让命令行和可重放记录成立；单页可视化只读取真实记录，不伪造网络自主行为。UI、云端、摄像头、大模型和复杂三维环境不进入第一条关键路径。

## 两天内的验收安排

第一天先完成独立提取、执行语义测试、最小预测任务与基线；所有输入必须先预测后揭示目标。开发数据上若连明显可辨别的扰动都没有稳定收益，停止界面扩张，不以固定脚本控制结果冒充自主回退。

第二天仅在第一天得到可重复现象后进行固定新种子验证、消融和展示。对照至少包括不更新、固定预算的普通更新、自适应步长和相同存储预算的整体恢复；不能只击败一个故意差的固定学习率。保留无扰动和长期改变场景，防止“总是不学”被误认成好策略。

独立推断单位是完整生成流与模型初始化的配对，不把每个时间点当独立重复。正式参数、种子划分、主指标和停止规则在新实验前通过 Research Design 冻结；当前没有科学实验结果。

## 文献邻近性与贡献边界

以下仅为本轮题目筛选时核验的原始资料线索，不代表已完成系统检索或全文审计，不登记为完成阅读的论文：

- Dohare 等，Nature 2024，Loss of plasticity in deep continual learning，DOI `10.1038/s41586-024-07711-7`：说明持续学习的可塑性问题值得研究，但本文不测试本项目的回退机制。
- Baydin 等，ICLR 2018，Online Learning Rate Adaptation with Hypergradient Descent，arXiv `1703.04782`：学习率本身的在线学习已有明确先例，不能以“学习如何学习”一句话宣称原创。
- Chu 等，ICML 2025，Provable and Practical Online Learning Rate Adaptation with Hypergradient Descent，PMLR 267:10768–10800：超梯度步长适应已有理论和实证研究，是后续方法比较与边界核验对象；其凸优化保证不能转移到本项目。
- Wang 等，CVPR 2022，Continual Test-Time Domain Adaptation，arXiv `2203.13591`：持续测试时适应中的误差积累与随机权重恢复已有先例；不同数据和监督条件下不能机械比较成绩。

科研贡献须落在具体信息约束、反馈时序、选择性回退的有效边界和成本上。参数分解、数组相减、可视化或单元测试通过本身不等于新的神经网络学习算法，也不能声称解决灾难性遗忘、通用终身学习或机器遗忘。

## 本轮已实现的范围

实际只提取 `fast_residual.py` 一个源码文件及 `test_fast_residual.py` 一个测试文件，源提交为 `aab9767615121a1bb517a89802e0ab0af306f12c`。源码初始逐字节复制，测试只改变导入命名空间；文件哈希与初始适配记录在 `v2v-source-manifest.csv`。

随后在本项目新增公开接口回归测试，实际复现并修复两项问题：第一，传入的增量数组与内部临时参数共享存储时，原实现可能记录错误的撤回量；第二，复合操作中的巩固比例无效时，原实现会先执行撤回才报错。修订分别通过输入快照、变更前参数校验解决，没有回写 V2V。

当前 `bash scripts/check.sh` 通过 20 项测试：4 项工程基础、11 项原模块测试、5 项新增边界测试。新增内容包含错误操作的状态保持、别名安全、选择性回退不等价于反事实重训的明确反例，以及 20 组确定性随机输入下小型非线性神经读出的巩固前后数值一致性。随机输入是软件属性检查，不是 20 次独立学习实验。

当前模块仍然由调用者提供回退请求与巩固比例；没有自动辨别污染、没有学会回退时机，也没有证据证明优于现有自适应学习方法。它允许下一步在不携带完整 V2V 的条件下检验这些问题，不是最终参赛模型。运行与安装均不需要原项目路径、GPU、Unity 或历史检查点；仅使用本项目的 NumPy 包与测试工具。

## 下一步需验证的反馈时序

一个最小诊断量可以是已保存增量 `δ` 与当前真实反馈产生的梯度内积 `b = ∇L(θ)·δ`。对足够小的撤回比例 r，一阶近似给出 `L(θ-rδ)-L(θ) ≈ -r b`。这只是局部灵敏度：b 为正并不证明删除整笔修改更好，更不保证下一条观察的损失下降。

任何基于该量的固定规则都必须标为人工设计的比较策略，不能冒充原 V2V 已验证的模型自主门控。若使用可学习的小门控，其输入、学习信号、初始状态与前置训练必须完全披露并单独验证。评分使用撤回决策发生之后的新观察，不能先看目标、修改模型，再把改后的同一条预测计作提前预测成绩。
