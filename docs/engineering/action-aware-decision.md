# 接受判断的动作分布输入

四步窗口的历史轨迹诊断见 `analysis/candidate-steering/README.md`。目标方向改善不保证下一步的实际朝向改善，因此新增可选输入配置 `actions`；不是把危险梯度或正确避险方向提供给模型。

## 输入与状态边界

保留已有140维局部观察、历史状态、候选参数增量与诊断统计，再增加38维：修改前的16方向概率、修改后的概率差，以及修改前后前进概率、修改前后平均转向命令、标称身体坐标位移差的前向和侧向分量。各维使用固定变换 `x / (1 + abs(x))`，不从测试场景估计归一化参数。

概率以当前同一观察和同一历史计算。候选参数预览与实际写入共用幅度约束及参数累积规则，只复制45维参数状态；不推进随机数、历史、环境或学习窗口。动作期望对16种方向各自的冻结动作输出加权，不把平均方向代入非线性动作模型。标称位移不含尚未发生的碰撞、减速或危险后果。

接受模型仍是线性预测器，新配置178输入、179参数。包含其余模块的候选总规模由1697变为1735，接近现有1732参数的普通多层感知机；这不证明基础能力等效。每只个体持有独立接受参数，部署时基础、记忆、动作和接受参数冻结，只有受限方向残差可以在线写入。

## 兼容与资格

默认 `parameters` 仍为140输入，保存为 `local-update-decision-v1`。新配置保存为 `local-update-decision-actions-v1`，按版本确定输入宽度；不把旧模型补零迁移为新模型。在线记录与实际接受判断使用同一特征构造方法。

四个行动步判断一次与是否接受是两件事：候选可以跳过；终止时仍处理不足四步的剩余反馈。新增输入不改变此时序。`survival-v1` 的旧接受器资格限制保持有效，8774历史验收页和历史结果不替换。

合成正负标签训练、检查点往返、候选预览及在线接受/跳过测试只验证工程接口。新的基础课程、保留集和复杂环境效果需要另立设计；当前不能声称该输入已提高生存或适应能力。

## 离线课程接口

采样计划显式设置 `include_action_features=true`，课程显式设置 `decision_profile="actions"`。每条配对的 `action_effects` 保存版本 `local-action-effects-v1` 与38个已做固定变换的有限值；在任何未来分支运行之前生成，未来结果仍只能作为标签。读取新课程时，缺失特征、错误宽度、越界或未知版本均拒绝，不补零。未启用时样本不增加该字段，模型和输入维度保持旧行为。

训练仍只读取各个体自己的训练世界，保留集不参与拟合，沿用课程指定的检查点间隔。可对同一份带动作记录的数据选择旧输入配置做后续输入对照；这不是已经执行的效果比较。

此接口仍使用原基础课程的配对奖励差标签，没有将它暗中改名为生存目标，也未修改任何冻结研究协议。生存优先的新课程和资格检查必须独立确定。本轮定向测试验证特征记录不改变非零候选、父轨迹与配对结果；临时测试模型不作为展示或正式比较模型。
