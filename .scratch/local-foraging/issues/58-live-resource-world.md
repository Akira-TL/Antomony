# 实时对照中的多食物源

父任务：[三组交互验收页](54-three-arm-acceptance.md)。当前先提供可独立测试的实时环境接口，不将旧回放改名为现场。

## 验收范围

- 沿用局部信号、冻结动作、真实拾取交付与保留个体状态的复活规则。
- 添加食物不重置世界步数或个体，库存及其局部信号真实生效。
- 携食死亡或耗尽退回原来源，不记交付；多源库存、携带和累计交付守恒。
- 非法位置和库存不产生部分修改；独立世界不共享资源或场。
- 默认单源训练与历史协议不变，未编辑新世界在相同动作下与既有世界逐步一致。

## 边界

此任务不训练或赋予接受模型资格，不交付页面、不改变8774；墙、陷阱和三组同步属于后续接口。

## 实际验证

`tests/interactive/test_resources.py` 与既有复活、群体、扰动、候选分支共30项测试通过。多源消耗、交付、耗尽归还、库存守恒、非法编辑原子性及场隔离均已核验；未编辑世界按固定动作连续80步与既有复活世界逐帧一致。
