# 基础课程的已知扰动恢复参照

候选分支评价增加显式恢复参照，只在训练诊断克隆中将在线残差恢复为0，保留稳定参数、已有记忆和随机状态；不作为部署算法。零残差时应与跳过完全相同。增加同范数、仅第四接收器连接上同向的初始扰动，作为有限课程比较；默认仍为原各向随机扰动。

实际诊断须另冻结设计和预算，不能把已知恢复答案带入学习输入或最终控制器。

验收：3项新增恢复与同向初始化测试，加13项既有候选、残差与分支测试通过。恢复只改克隆的快速残差，不删除稳定参数、不推进主随机流、不共享记忆；零残差为精确负对照，默认采样协议行为不变。
