# 局部返巢失败诊断

## 最小失败与原因

固定种子9701，单只沿直线前进到探索预算耗尽（30步），留下环境原有离巢轨迹，随后用局部规则返回，返巢储备160步。没有训练、食物搜索或其他个体碰撞。原环境空载和携食均失败，结束距巢约5.946和2.069。

在折返前沿路径取49个点，其中11点局部梯度背离巢穴。仅停止空载返程释放，结束距离从5.946变为2.069，仍失败；仅把初始朝向倒转也失败。人工全域单调源正对照两种状态均43步返回，说明当前规则能追随该简单信号，但不证明它能处理任意真实轨迹。全域源只用于诊断，绝不用于训练或正式比较。

平滑且不累加的轨迹版本单独使用仍停在巢外；用户随后批准有限范围巢穴信号。仅加入巢穴信号后携食可返回，空载仍被折返点的高峰困住；两项合用，在该直线测试中均45步返回。初次完整原型输出为 `logs/local-return-20260926T084411-2.jsonl`，正式实现可通过下述脚本复查。

## 明确的环境变化

新增 `trail_profile="bounded-local-v2"`，仅用于新训练或检查的显式配置。沉积为以个体实际位置为中心、标准差0.65、半径1.95截断的平滑分布，强度沿实际行程衰减；逐位置取已有浓度与新分布较大值，浓度最多8。出生位置先留下标记。共享场的扩散和蒸发仍执行，同伴可刷新同一路径的标记，不共享模型。

这不是质量守恒的化学模型，也不再通过无限相加表示经过的个体数，是明确的导航信号建模变化。原地释放仍会从零增加浓度、刷新衰减标记，但不会因停留时长把远处地点变成比上游更强的峰。低浓度奖励公式不改；该变化不保证探索奖励没有其他可利用方式。

巢穴源显式使用 `nest_signal_strength=1`、`nest_signal_radius=1.5`，仅作用于第二接收器，范围外源贡献严格为零。最远接收点距身体0.9，因此身体距巢超过2.4时不能靠此源导航。模型输入仍为局部响应与自身状态，不包含巢穴坐标、方向或距离。

旧默认仍为单格累加版本、巢穴源强度0，历史配置和检查点不会被悄悄换环境。所有新比较须给所有组同一环境版本，并重新核对基础能力，不能直接沿用旧环境成绩。

## 验证与边界

`bash scripts/diagnostics/local-return.sh` 输出16个小型诊断条件，只用于检验上述机制。`tests/training/test_local_return_regression.py` 在四朝向、两携带状态上要求真实循迹返回；其他测试核对旧轨迹场逐值一致、沉积有限范围、通道隔离和禁止原地累加高峰。

此轮只修正已定位的信号形成问题，没有修改模型、奖励训练或神经组动作。复杂路径、交叉轨迹、群体搜索和陌生环境适应仍需验证。
