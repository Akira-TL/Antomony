# 连续对照验收控制页

## 打开与运行

当前本机入口：<http://localhost:8774/acceptance.html>。

```bash
env UV_CACHE_DIR=/tmp/mathhackson-uv-cache bash scripts/acceptance/start.sh --managed
bash scripts/acceptance/stop.sh
```

通过本项目独立用户级服务保持运行；默认只绑定127.0.0.1。端口冲突时拒绝覆盖，可显式设置 `PORT`。没有修改8771、8772训练服务，未修改网络、代理、nginx或ForgeRelay。修改前端后使用 `npm --prefix web run build`，再刷新页面；后端变更需用上述脚本重启。

## 数据与操作

批次菜单保留登记批次 `logs/continuous-adaptation/20260926T123655-2/` 及[正式分析](../../analysis/continuous-adaptation/README.md)，另提供[远距场景](distant-acceptance.md)的独立工程试跑；远距批次完整后默认选中，食物距巢8至10，页面标注实际距离及未作效果判定。原80世界及其分析不变。这是实际记录回放，不是新训练、实时重新模拟或参数快照续跑。

四条件、四世界种子均可选；左侧为学习接受，右侧可选固定接受、全部跳过、普通MLP、纯规则。播放、暂停、单步及时间轴作用于两侧的同一时间。早停世界保持终态，不补造动作、写入或交付。初始默认暂停，页面明确保留本接受策略未通过采用条件的状态，交付和死亡差值不截断负值。

个体参数可选组别、个体和参数模块，每页12条折线，悬停读取真实值。45个方向参数来自逐项更新记录；冻结的基础、近期/稀疏记忆、动作及接受参数来自该个体真实初始化文件，经本批分析确认整个运行不变。折线持有值直到下一次记录，不插值伪造中间权重；提前死亡后保持最后值，显示个体已终止。纯规则不创建神经模型，参数列表为空。

接收器柱状图读取中心位置八个实际观察值，悬停查看数值。前三项分别使用食物源黄色、离巢青色、携食轨迹橙色。全场信息素没有随原始轨迹保存，因此页面不绘制虚构浓度场。青色圈表示有限巢穴源，红色圈表示危险/减速作用区域和终止个体；不是额外模型输入。

## 只读边界

接口只允许登记世界身份及有效个体读取，没有参数写入或训练接口；实际POST参数接口返回405。模型文件、研究数据库和原始轨迹不经页面修改。后端读取参数时不创建或调用神经网络。布局初态由同种子环境初始化取得，逐步位置、危险源及事件来自原始记录。

渲染复用现有Three.js场景。跨多步跳转时仅清理显示用步态插值，避免旧落足点拉长；不修改模型动作或原始腿部实现。画面中的腿是运动可视化，原始研究记录没有每条腿的物理数据。
